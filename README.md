# Diva: пресет по аудиореференсу

[Скачать комплект одним ZIP-файлом](Diva_lead_reference_v1.zip). Открой файл на GitHub и нажми **Download raw file** (значок скачивания). Также можно скачать весь репозиторий через **Code → Download ZIP**.

Все подготовленные материалы доступны отдельно в папке [diva-lead](diva-lead):

- [Черновой пресет Diva `.h2p`](diva-lead/Diva_Lead_Reference_v1.h2p).
- [MIDI-фраза, 180 BPM](diva-lead/Lead_reference_180BPM.mid).
- [Инструкция загрузки и настройки эффектов FL Studio](diva-lead/FL_Studio_settings_RU.md).
- [Исходный аудиореференс WAV](diva-lead/Diva_original_lead_reference.wav).
- [Параметры чернового пресета в JSON](diva-lead/preset_settings.json).

Пресет загружай через встроенный браузер **PRESETS** в Diva. MIDI импортируй в Piano Roll её канала.

Это первая реконструкция по спектральному анализу. Загрузка в Diva и совпадение звука 1:1 ещё не проверены в FL Studio. Для следующей итерации нужен WAV-рендер приложенного MIDI с этим пресетом, сначала без эффектов, в формате 24-bit / 48 kHz.

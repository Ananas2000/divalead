# Diva: реконструкция лида по видео

**V4 без эффектов.** На дорожке Diva в видео видны три удерживаемые ноты, длительности **1½ → 1½ → 1 доля**, темп **180 BPM**. MistaTowa Vol.3 в подборе не используется. Исправлены повторные срабатывания, режим голосов, завершение огибающей и громкость по высоте нот.

Пресет получен рендером присланного Diva revision 16519 под Wine. После сохранения, повторной загрузки и запуска в свежем экземпляре совпали все 281 параметр; эффектов и перегруза нет. **99% сходства на слух не подтверждены:** здесь выполнено численное сравнение, FL Studio не запускалась. Для готового воспроизведения загрузи `.h2p` через собственный браузер **PRESETS** Diva и импортируй MIDI `PERFORMANCE`; в Diva **ARP Off, FX1 Off, FX2 Off**. Файл `PATTERN` содержит исходную структуру из трёх длинных нот, а `PERFORMANCE` разворачивает повторы и октавы для нашей реконструкции. Подробности этой разницы находятся в инструкции.

Для скачивания отдельного файла на GitHub нажми **Download raw file**. Весь репозиторий доступен через **Code → Download ZIP**. [Исходники анализа и хоста рендера](diva-lead/v4/analysis) позволяют повторить измерения и воспроизвести тестовую партию со своим VST2-плагином.

Предыдущие версии сохранены для сравнения: [v3](Diva_lead_reference_v3.zip), [v2](Diva_lead_reference_v2.zip), [v1](Diva_lead_reference_v1.zip). Их MIDI из пяти смен высоты отражал раннюю реконструкцию; для структуры исходного видео используй материалы v4.

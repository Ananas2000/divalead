# Проверка v4

`compare.py` повторяет измерения по WAV из комплекта. Установка зависимостей и запуск:

```bash
python -m pip install -r analysis/requirements.txt
python analysis/compare.py
```

Измерение использует распределения энергии спектра, нормированные отдельно в каждом окне. Это численная проверка тембра и атак; она не устанавливает процент сходства на слух и не сравнивает все фазовые отношения между L/R. Общая громкость, динамика и стереокорреляция дополнительно записаны в `validation.json`.

`diva_vst2_host.c` — исходный код хоста, которым выполнены рендеры. Он воспроизводит фиксированную тестовую партию; командой `pattern` выбираются 3 удерживаемые ноты, прежние 5 смен высоты или 8 развёрнутых атак. Рендеры v4 используют 8 атак, а видимый исходный паттерн содержит 3 ноты. MIDI-протокол, выборка 48 кГц, темп 180 BPM, короткий прогрев после загрузки пресета и сброс MIDI находятся в исходнике.

Хост рассчитан на **VST2**: присланный файл с расширением `.vst3` экспортирует `VSTPluginMain`. Нативный VST3-плагин с другим ABI этим хостом не поддерживается. Сам плагин и сторонние банки пресетов в репозиторий не включены.

Для сборки Windows-хоста нужен MinGW-w64:

```bash
x86_64-w64-mingw32-gcc -O2 -static -o analysis/diva_host.exe analysis/diva_vst2_host.c -lm
```

Затем на Windows можно передать путь к своему VST2-плагину:

```powershell
python analysis/replay.py --plugin "C:\path\Diva.dll"
```

На Linux нужен установленный Wine либо путь к переносимой сборке через `--wine`; также доступны `--prefix`, `--wine-dll-dir` и `--wineserver`. `replay.py` выполняет сухой рендер без выравнивания начала. `ALIGNED` в комплекте добавляет 992 начальных нулевых сэмпла для сравнения с вырезкой видео.

Исходное видео кодировано HE-AACv2 примерно 32 кбит/с. Отдельная проверка с таким профилем выполнена с [FDK AAC](https://github.com/mstorsjo/fdk-aac) и [fdkaac](https://github.com/nu774/fdkaac); это не обработка выдаваемого пресета. Бесплатные банки для поиска структуры получены через [официальную библиотеку u-he](https://u-he.com/PatchLib/diva.html): проверено 2177 уникальных файлов, 2101 сухой рендер прошёл критерий слышимости. Финальный пресет продолжает нашу реконструкцию, а не копирует один из этих банков.

# Diva v4: сухой лид и партия из видео

MistaTowa Vol.3 в реконструкции не используется. На дорожке Diva в видео видны **три длинные ноты**, с длительностями **1½ → 1½ → 1 доля**. Темп — **180 BPM**. В нашей настройке их высоты — **F3 → C#3 → C3 в FL Studio**, MIDI **41 → 37 → 36**. Абсолютные названия клавиш на миниатюре видео не читаются; регистр выбран по аудио для этого пресета.

V4 проверена рендером в присланном Diva revision 16519 под Wine. Сохранённый `.h2p` загружен заново и в отдельный свежий экземпляр: все 281 параметр совпали. **FL Studio здесь не запускалась, прослушивание не выполнялось и 99% сходства на слух не подтверждены.** Остаётся отличие по ширине стерео.

## Что открыть в FL Studio

1. Загрузи `Diva_Lead_Reference_v4_DRY.h2p` через собственный браузер **PRESETS** в Diva. Файл можно поместить в пользовательскую папку пресетов Diva и обновить браузер.
2. Установи **180 BPM**, отключи обработку канала и мастера для сравнения.
3. Для проверенного варианта импортируй **`Diva_PERFORMANCE_REFERENCE_180BPM.mid`** в Piano Roll. В Diva **ARP Off**, **FX1 Off**, **FX2 Off**. MIDI уже содержит повторные срабатывания и октавы.

| MIDI-файл | Содержимое |
|---|---|
| `Diva_PATTERN_3notes_VIDEO_180BPM.mid` | Три удерживаемые ноты по структуре видео: начало 0 / 1½ / 3 доли, длительность 1½ / 1½ / 1 доля. Размещай эту фразу в Playlist каждые два такта. |
| `Diva_PERFORMANCE_VIDEO_180BPM.mid` | Развёрнутая реконструкция атак: две фразы, повтор через **8 долей**, как в видео. |
| `Diva_PERFORMANCE_REFERENCE_180BPM.mid` | Та же реконструкция, повтор через **7 долей**, чтобы сравнить с присланной аудиовырезкой. |

Три исходные ноты и восемь атак — разные представления партии. В развёрнутом варианте одна фраза имеет высоты **F3 → F3 → F4 → C#3 → C#3 → C#4 → C3 → C3**, по одному шагу на ½ доли. Повторы проверены как способ приблизить фазу и атаки референса; это **не утверждение, что на видео нарисованы восемь нот** или что удалось прочитать настройки оригинального арпеджиатора.

Для варианта с тремя удерживаемыми нотами можно попробовать арпеджиатор **канала FL Studio**: Up, Range **2 октавы**, Repeat **2**, Time **⅛**, Gate **91.45%**, Swing около **0%**, Slide Off; ARP самой Diva остаётся Off. Эта цепочка в FL Studio не проверена. MIDI `PERFORMANCE` служит готовым проверенным вариантом.

## Крутилки Diva

Это значения дисплея Diva. Cutoff и ADS ниже — **не герцы и не миллисекунды**. Полный список, включая normalized-значения 0…1, находится в `Diva_v4_DRY_parameters.tsv`. Для FL-полей в процентах normalized-значение умножается на 100.

| Блок | Значение |
|---|---|
| Oscillator | **Dual VCO**, Shape **analog1** |
| VCO 1 | **Triangle + PWM**, Saw Off; диапазон **8′**, `OSC: Tune1` **-0,06** |
| VCO 2 | **Pulse**, остальные волны Off; диапазон **2′**, суммарный `OSC: Tune2` **24,07**, то есть +24 и небольшая расстройка |
| PW | **51,76** |
| MIX | **7,25** |
| Filter | **Ladder, 24 dB, clean** |
| Cutoff / Emphasis / KYBD | **143,99 / 12,89 / 19,86** |
| ENV 1 | **ADS**, Attack **11,39**, Decay **12,07**, Sustain **100**, **Release On** |
| ENV 1 Velocity / KeyFollow | **0 / 0** |
| Amplifier | VCA **Env1**, Volume **48,50**, Pan **-39,33** |
| Vol Mod | **Adder**, глубина **-90,00**; VCA Mode **lin** |
| MODIFICATIONS → Adder | Input 1 **KeyFollow2**, Input 2 **KeyFollow2** |
| Mode / Priority / Voices / Stack | **poly / last / 3 / 1** |
| Fine Tune | **-1,13 cents**, Transpose **0** |
| TRIMMERS: `OPT: TuneSlop` | **3,27** |
| `OSC: Drift` | **17,46** |
| FM / Sync / Noise / Glide / Vibrato | **0 / Off** |
| Глубины модуляции pitch, PW и cutoff | **0** |
| Accuracy / Offline Accuracy | **great / same** |
| Output | **119,61** |
| Effect 1 / Effect 2 / Diva ARP | **Off / Off / Off** |

Небольшие точные значения Tune1 и триммеров доступны через **Browse parameters** плагина в FL Studio. Пресет сохраняет также внутренние таблицы вариаций голосов; для воспроизведения всей настройки загружай `.h2p`.

В модели **ADS** включённый Release использует **Decay**. Здесь Decay = 12,07 задаёт короткое завершение, а **poly** позволяет повторным нотам менять фазу и накладываться на это завершение. Это существенное исправление относительно v3 с mono и выключенным Release.

## Аудиосравнение

`AB_reference_v3_v4_DRY.mp3` и WAV содержат три отрезка с одинаковой общей RMS-громкостью:

| Начало | Отрезок |
|---|---|
| 0:00 | Исходный референс |
| 0:04,168 | Предыдущая v3 DRY, тот же файл, который ты прислал |
| 0:08,336 | Новая v4 DRY |

Начала аудио выровнены: v3 на 20 мс, v4 на **20.67 мс**. `Diva_v4_DRY.wav` — сухой рендер; `Diva_v4_DRY_ALIGNED.wav` содержит тот же сигнал с добавлением начальной тишины для совмещения с вырезкой. Встроенные эффекты и внешняя DSP-обработка выключены. В паузах A/B по 0,5 секунды.

## Что показывает проверка

После выравнивания ошибка распределения энергии в спектре всего фрагмента снизилась с **0,114 у v3** до **0.094 у v4**. Отдельно проверялись обертоны, динамика и атаки. Метод и точные числа находятся в `validation.json`; скрипт `analysis/compare.py` повторяет измерение по файлам.

Это численные расстояния, **не процент сходства на слух**. Оригинальное видео содержит **HE-AACv2 около 32 кбит/с**, который влияет на фазу и стерео. Кодек проверялся отдельно; в выдаваемый сухой рендер его не добавляли. У референса корреляция L/R **0.921**, у v4 **0.999**: сухая реконструкция звучит пространственно уже. Оригинальный пресет и настройки канального арпеджиатора по этому видео не установлены.

# Три удерживаемые ноты — исследовательский вариант

Это лучший по общему критерию трёхнотный источник из выполненной серии, заново отрендеренный через тот же Finish v58, что и основной вариант. **Он пока уступает основному v58 и не является достигнутым совпадением.**

В Piano Roll — три ноты на фразу: MIDI **41 → 37 → 36**, длительности **1½ → 1½ → 1 доля** при 180 BPM. В MIDI сохранены два прохода, повтор через 8 долей: всего 6 note-on. Повторные срабатывания и октавы создаёт **внутренний арпеджиатор Diva**. Это проверенная работающая гипотеза для трёх удержаний; настройки автора видео не установлены.

## Загрузить в FL Studio

1. Для готового аудио перетащи `Diva_THREE_HELD_REFERENCE_EDIT.wav` или `Diva_THREE_HELD_FULL_180BPM.wav` в Playlist. Normalize Off, Pitch 0, Time stretching Resample, Time Reset, канал 0 dB, pan по центру. На эти готовые WAV Finish повторно не ставится.
2. Для живого синтезатора загрузи `Diva_THREE_HELD_RESEARCH.h2p` через браузер PRESETS самой Diva. Установи 180 BPM и 48 kHz.
3. Импортируй **`Diva_THREE_HELD_180BPM.mid`** в Piano Roll этого канала. Он содержит именно удержания. MIDI основного v58 с 16 нотами для этого пресета не используется.
4. В этом пресете ARP **On**, Direction **up+dn 2**, Octaves **2**, Multiply **1x**, Order **serial**, Restart **none**. Clock: 100%, TimeBase **1/8**, Swing 0. Эти значения уже сохранены в H2P.
5. На Insert поставь основной `Diva Lead Finish v58 WIP` из корня комплекта: Amount 100%, Output +1,85 dB, Mix слота 100%. Громкость канала перед эффектом — 0 dB, фейдеры Insert и Master — 0 dB, дополнительная обработка отключена. Сохрани настройки голосов и эффектов самого пресета; это отдельная трёхнотная настройка, не исходный пресет v57.
6. Для точного сохранённого источника вместо живой Diva можно использовать `Diva_THREE_HELD_SOURCE_48k.wav` через Finish v58. В нём ещё нет Finish. Начинай с начала клипа, PDC включена. Внутренняя история живой Diva в FL может отличаться от проверенного прогрева под Wine.

`AB_REFERENCE_V58_THREE_HELD_WIP.wav` в корне комплекта содержит оригинал с 0 с, основной v58 с 4,168 с, этот трёхнотный вариант с 8,336 с. В сравнении громкость каждого кандидата выровнена одним общим RMS-множителем; поканальной и понoтной коррекции нет.

Для трёхнотного WAV заново проверены фактический рендер Diva, все 281 параметр, 12 входящих событий и обработка Windows DLL относительно native-расчёта. Собственная независимая NEW-база полного расчёта для этого дополнительного контроля отдельно не перестраивалась; она есть для выбранного основного v58. GUI FL Studio здесь не тестировался.

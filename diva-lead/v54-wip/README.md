# Diva Lead v54 WIP

Промежуточный бэкап. Совпадение с оригиналом ещё не достигнуто и на слух не подтверждено.

После v53 уточнены четыре параметра встроенной реверберации Diva: Wet 1,12 → 1,88; Decay 35,25 → 33,25; Damp 72 → 54,28; Diff 92 → 84. Остальные 277 параметров Diva и MIDI прежние. На новом источнике совместно уточнены существующие усиления и реакция гармоник, затем верхний диапазон и общие фазы.

Дополнительно уменьшен измеренный перекос каналов относительно оригинала. Использованы существующие заключительные стереокривые: 42 свободных значения, три опорных значения при 1600 Гц сохранены нулевыми. Выбранный вариант прошёл строгие ограничения на изменение гармоник, спектра, огибающей и уровней нот. Алгоритм, 638 спектральных значений, 47 состояний усиления, FFT, фильтры и PDC прежние. Это не означает полного устранения различий.

## Использование и WAV

1. Загрузить `Diva_Lead_v54_WIP.h2p` в предоставленную Diva.
2. Следом поставить `Diva_Lead_Finish_v54_WIP_x64.dll`: Amount = 1, Output = +1,852506397 dB, PDC включена.
3. MIDI — `Diva_PERFORMANCE_VIDEO_180BPM.mid`, 180 BPM.

Нужны пресет и эффект именно v54. Бинарник Diva не включён; GUI FL Studio не проверялся.

`AB_REFERENCE_V54_WIP_HARMONIC_RESPONSE_AND_UPPER.wav`: оригинал → v54, начало v54 **4,168 с**. Трёхчастный WAV: оригинал → v53 → v54, начала 0 / 4,168 / 8,336 с. Один RMS-множитель на весь фрагмент; WAV без потерь. MP3 не включён.

## Проверки

Источнику предшествовали 13 контрольных и 62 уточняющих рендера настоящей Diva. Выбранный источник проверен повторными загрузками и полным дампом 281 параметра. После каждого следующего этапа обработки выполнены свежий рендер Diva, настоящий Windows-эффект, сопоставление с native, расчётом подбора и независимой цепочкой. Фактические статусы оптимизаторов и проверок — `analysis/research_selection.json`.

Для нового источника заново рассчитана независимая база **268** перед STFT. Базы 247 и 197 для него не используются. Полная цепочка использует отдельное ядро 43 параметров, SciPy FIR/согласование энергии/Side/динамику/возбудитель, независимый входной трекер и десять фильтров, затем независимую NumPy/SciPy-спектральную обработку.

Максимальная ошибка полной независимой цепочки — **1.837435822e-07**. Допуски прежние: 5e-7 для базы, 3e-7 для полной цепочки и 2e-7 для спектрального WAV-фикстура. Ограничения выбора стереоварианта проверены повторно по настоящему Windows-рендеру в `analysis/actual_timbre_safeguards.json`.

Проверены два свежих рендера Diva, Windows/native/cache, блоки 47/127/128/511/512/2048, preroll 3/17, 44,1/48/96/192 кГц, состояние, PDC, тишина, Amount = 0 и каналы. Независимые проверки: 638 значений, 12 произвольных входов без MIDI, переходные сигналы, отдельно включённые поздние гармоники, масштаб входа и причинность. ZIP проверяется по CRC, всем SHA256 и извлечённому независимому WAV-расчёту.

Исходники эффекта и независимый расчёт включены. В DSP нет записи оригинала, MIDI, нот или расписания исполнения; монтаж сравнения внешний. MistaTowa не использовался. Временные `.so`/`.exe` не включены. Отличия тембра и стерео остаются; подбор продолжается.

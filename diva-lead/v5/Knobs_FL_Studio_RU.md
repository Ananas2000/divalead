# Diva Lead v5 — готовая цепочка для FL Studio

**V5 состоит из пресета Diva и одного готового эффекта `Diva Lead Finish v5`.** Основу звука составляет сухой v4, который был близок к референсу. Эффект добавляет подобранное стерео по частотам и небольшую коррекцию тембра. Все его настройки уже сохранены в плагине.

`Diva Lead Finish v5` — дополнительный Windows x64 VST2-эффект, созданный в этой работе. Это воспроизводимая обработка нашей реконструкции; оригинальная цепочка эффектов из видео не установлена.

## Загрузка в FL Studio

1. Загрузи **`Diva_Lead_v5.h2p`** через собственный браузер PRESETS Diva.
2. Назначь Diva отдельный **Insert микшера**. Громкость микшера — **0 dB**, Pan микшера — **по центру**. Для сравнения громкости установи Channel Volume на **100%**.
3. Положи **`Diva_Lead_Finish_v5_x64.dll`** в свою папку VST2. Например, создай папку в Documents, добавь её в **Options → Manage plugins → Plugin search paths** и запусти **Find installed plugins**.
4. Вставь **Diva Lead Finish v5** в первый FX-слот Insert с Diva. У эффекта уже выставлены **Amount 100%**, **Output +1,88 dB**. Внутри самой Diva **FX1 Off, FX2 Off, ARP Off**. Эффект обрабатывает только лид на этом Insert; сэмпл MistaTowa Vol.3 в подборе не используется.
5. Установи **180 BPM** и импортируй MIDI `PERFORMANCE`. Для структуры оригинального видео используй **`Diva_PERFORMANCE_VIDEO_180BPM.mid`**, для сравнения с аудиовырезкой — **`Diva_PERFORMANCE_REFERENCE_180BPM.mid`**. Это одна реконструкция атак с разной длиной паузы между фразами.

Для A/B отключи дополнительную обработку Insert и мастера. Встроенный chorus из предыдущего тестового пресета здесь не включается: весь выбранный вариант обработки находится в Lead Finish.

## Партия

В видео нарисованы **три удерживаемые ноты**: начало **0 / 1½ / 3 доли**, длительности **1½ / 1½ / 1 доля**. Они сохранены в `Diva_PATTERN_3notes_VIDEO_180BPM.mid`. Для этого пресета выбраны MIDI **41 / 37 / 36**, то есть **F3 / C#3 / C3** в FL Studio. Абсолютные названия клавиш на миниатюре видео не читаются; регистр выбран по аудио.

MIDI `PERFORMANCE` уже разворачивает повторы и октавы в восемь атак на фразу: **F3 → F3 → F4 → C#3 → C#3 → C#4 → C3 → C3**. Арпеджиатор Diva остаётся выключенным. Это способ реконструкции звучания; настройки оригинального канального арпеджиатора не прочитаны. В VIDEO повтор идёт через **8 долей**, в REFERENCE — через **7 долей**, как в вырезке.

## Эффект Lead Finish

| Доступная крутилка | Значение |
|---|---|
| **Amount** | **100%** |
| **Output** | **+1,88 dB** |

Коррекция тембра, фазовая модуляция и задержки стереодобавки подобраны совместно и уже настроены. Для получения готового результата дополнительные крутилки не требуются. Исходный код и точные настройки находятся в `analysis/` и `Finish_settings.json`.

## Аудиосравнение

`AB_reference_v4_v5_FINAL.mp3` и WAV содержат фрагменты на одинаковой общей RMS-громкости:

| Начало | Фрагмент |
|---|---|
| **0:00** | Оригинальный референс |
| **0:04,168** | Предыдущий сухой v4 |
| **0:08,336** | Готовый v5: Diva + Lead Finish |

`Diva_v5_FINAL.wav` — рендер готовой цепочки. `ALIGNED` содержит тот же сигнал с добавлением **20,67 мс начальной тишины** для совмещения с вырезкой. `Diva_v5_DIVA_DRY.wav` содержит только основу Diva.

## Что проверено

Оба плагина реально отработали под Wine. У Lead Finish проверены сохранение состояния, идентичный результат при блоках 512 и 93 сэмпла, повторный старт после работы в фоне, выключение обработки и отсутствие шума на тишине. Дополнительно проверены 44,1 и 96 кГц. Выход конечный и без перегруза. Готовый Windows VST даёт расчётный результат с абсолютной погрешностью менее **6 × 10⁻⁸** по амплитуде в проверенном прогоне.

В активных участках корреляция L/R **0,999 у dry v4 → 0,922 у v5**, у оригинала **0,922**. Средняя ошибка корреляции в пяти диапазонах снижена с **0,305 до 0,031**. Взвешенная ошибка обертонов снижена с **5,18 до 3,74 dB**; расстояние по спектру всего фрагмента изменилось умеренно: **0,094 → 0,093**. Есть небольшие оставшиеся отличия в динамике и атаках. Это численные измерения, **не процент сходства на слух**.

FL Studio здесь не запускалась; субъективного прослушивания не было. Оригинальный пресет и эффекты не установлены. Подробная проверка — в `validation.json`, независимый пересчёт по WAV — `analysis/compare.py`.

# Diva Lead v47 WIP — source and harmonic balance

Совпадение с оригиналом не достигнуто. Это проверенный промежуточный бэкап.

Изменены Tune2 второй синхронизированной осцилляторной секции с 24,00 до 24,02, сила коррекции гармоник, прежние 12 фазовых коэффициентов и последние пять существующих поправок Side. MIDI сохранён. По измерениям гармонический баланс и спектр коротких окон стали ближе; часть других показателей ухудшилась. Это не оценка сходства на слух.

## Использование

1. Загрузить `Diva_Lead_v47_WIP.h2p` в предоставленную Diva.
2. Следом поставить `Diva_Lead_Finish_v47_WIP_x64.dll` в FL Studio Windows x64: Amount = 1, Output = +1,852506397 dB.
3. Для исполнения использовать `Diva_PERFORMANCE_VIDEO_180BPM.mid`, темп 180 BPM.
4. Для сравнения использовать `Diva_v47_VIDEO_REFERENCE_EDIT.wav` или A/B.

Эффект требуется вместе с пресетом. Бинарник самой Diva в ZIP не включён. PDC при 48 кГц — 12416 кадров.

`AB_REFERENCE_V47_WIP_SOURCE_AND_HARMONIC_BALANCE`: оригинал → v47, v47 начинается с **4,168 с**. Трёхсторонний A/B: оригинал → v46 → v47, начала 0 / 4,168 / 8,336 с. На каждый фрагмент применяется один общий множитель RMS; нормализации отдельных нот нет.

## Что проверено

Два свежих запуска предоставленной Diva дали одинаковый исходный WAV. Все 281 параметр сверены; относительно v46 изменился только параметр 87, Tune2. Windows-эффект проверен при блоках 47/127/128/511/512/2048, preroll 3/17 и частотах 44,1/48/96/192 кГц. Проверены возврат состояния, PDC, каналы, точный ноль на тишине и Amount = 0.

Независимая полная цепочка использует отдельно рассчитанный core, SciPy FIR/20 Side-фильтров, отдельные dynamics/exciter, независимый трекер и SOS, затем NumPy/SciPy STFT. После изменения источника и Side рассчитана новая база 197. Старая база 176 для v47 не используется.

Максимальная ошибка полной независимой цепочки: **1.891279992e-07**. Проверены 12 произвольных входов, четыре переходных сигнала и два входа с включённой только поздней группой. Сохранены причинность и инвариантность спектрального шага к масштабу входа. Это проверки реализации, не доказательство совпадения тембра.

587 спектральных коэффициентов: прежние 575 сохранены точно, 12 общих фазовых значений изменены. Значения целевых мощностей и стереоотношения сохранены. У каждого порядка 2–24 теперь своя постоянная сила коррекции; детекторы и состояния уже существовали. Гармоника 4 получает силу 0,25; 2/3/5/6 — 0,02785410234612714; 7–24 — 0,85. Предел желаемого изменения ±6 dB применяется перед силой. Сглаживание мощности 4,562899787 мс сохранено. Стереокоррекция и её сглаживание сохранены v46.

47 состояний, прежние FFT/фильтры/PDC. Нот, MIDI, расписания исполнения или оригинального аудио в алгоритме эффекта нет. Короткий референсный WAV использует прежний внешний монтаж, описанный в `reference_edit.json`.

Полосы «между гармониками» включают модуляцию, оконные утечки и влияние кодека. Эти измерения не выделяют шипение и не подтверждают субъективную чистоту. FL Studio GUI и прослушивание этой версией проверки не выполнялись.

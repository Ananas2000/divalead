# Diva Lead v56 WIP

Промежуточный бэкап подбора тембра. Совпадение с оригиналом ещё не достигнуто и на слух не подтверждено.

Изменены только 93 существующих коэффициента общего усиления гармоник в эффекте после Diva. Подбор теперь дополнительно учитывает распределение энергии по 40 частотным полосам с шагом в шкале ERB. Это аналитический критерий подбора, в эффект новая обработка не добавлена. Источник Diva, все 281 параметр, исходные аудиосэмплы, MIDI, обработка до STFT и остальные настройки эффекта прежние относительно v55. Явные настройки стерео также прежние; изменение усилений всё же может немного изменить измеряемые стереопоказатели.

По выбранному критерию распределение энергии ближе к оригиналу. При этом ошибка отдельных гармоник и спектра всего фрагмента немного выросла: все изменения показаны ниже. Это не подтверждает полного совпадения или слышимого улучшения. Предыдущая версия v55 сохранена.

## Использование и сравнение

1. Загрузить `Diva_Lead_v56_WIP.h2p` в предоставленную Diva.
2. Следом поставить `Diva_Lead_Finish_v56_WIP_x64.dll`: Amount = 1, Output = +1,852506397 dB, PDC включена.
3. MIDI — `Diva_PERFORMANCE_VIDEO_180BPM.mid`, 180 BPM.

Бинарник Diva не включён. Пресет v55 даёт тот же источник, у пресета v56 изменена подпись. Для этих WAV нужен эффект v56. Настройки Diva: 3 голоса, poly, stack 1. GUI FL Studio не проверялся.

`AB_REFERENCE_V56_WIP_ERB_BAND_ENERGY.wav`: оригинал → v56, начало v56 **4,168 с**. `AB_REFERENCE_V55_V56_WIP_ERB_BAND_ENERGY.wav`: оригинал → v55 → v56, начала 0 / 4,168 / 8,336 с. На каждый целый фрагмент применён один RMS-множитель; PCM24 WAV без потерь. Содержимое и позиции сегментов проверены.

## Проверки и происхождение

Подбор 330 завершился по бюджету 60 nfev, а не по достижению совпадения. Для бэкапа выбран сохранённый шаг 1321, прошедший ограничение по гармоникам; более поздние шаги с меньшей ERB-ошибкой нарушили это ограничение. Снимок был отдельно проверен свежим рендером Diva и Windows-эффектом ещё во время подбора. Завершившийся поиск выбрал тот же шаг. Дополнительно рассчитаны 25 сочетаний с отдельным подбором основной матрицы: по совместному критерию сохранён вариант без этого дополнительного изменения матрицы.

Выбранный WAV дважды подтверждён свежими загрузками Diva с проверкой всех 281 параметра и исходных аудиосэмплов. Эффект пересобран с новым VST ID `0x444c466f`; DLL v55 не переименовывалась. Проверены Windows/native/независимый расчёт, блоки 47/127/128/511/512/2048, preroll 3/17, частоты 44,1/48/96/192 кГц, состояние, PDC, каналы, тишина и Amount = 0. Переносимые проверки включают 12 произвольных входов без MIDI, переходные сигналы, поздние группы гармоник, масштаб входа и причинность.

Источник 267 и обработка перед STFT прежние, поэтому независимая база 268 остаётся применимой. Базы 247 и 197 для этого источника не используются. Полная независимая цепочка использует отдельное ядро 43 параметров, SciPy FIR/согласование энергии/Side/динамику/возбудитель, независимый трекер и десять фильтров, затем независимую NumPy/SciPy-обработку спектра.

Максимальная ошибка полной независимой цепочки — **1.881550227e-07**. Допуски прежние: 5e-7 для базы, 3e-7 для полной цепочки, 2e-7 для WAV-фикстура, 2e-10 для спектральных проверок на произвольных входах.

Алгоритм, формы массивов, фильтры, FFT и PDC прежние. В основных массивах 638 коэффициентов, дополнительно 23 веса групп: 661 значение; опоры и скалярные настройки считаются отдельно. Состояний усиления 47. В DSP нет записи оригинала, MIDI, нот или расписания исполнения. Монтаж и измерения выполняются снаружи эффекта. MistaTowa не использовался. Исходники эффекта и независимый расчёт включены. ZIP проверен по CRC, всем SHA256 и независимому расчёту извлечённого WAV-фикстура. Подбор продолжается.

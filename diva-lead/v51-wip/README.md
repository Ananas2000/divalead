# Diva Lead v51 WIP — уточнение самого тембра

Промежуточный бэкап. Совпадение с оригиналом ещё не достигнуто и на слух не подтверждено.

Продолжен подбор после v50: уточнены мощность отдельных гармоник, центральная составляющая между ними, верхняя спектральная матрица и форма пиков. Затем совместно подобраны существующие цели мощности, силы выравнивания гармоник и скорость их реакции; в конце — взаимные фазы. Приоритет — сам звук. Отдельная цель подбора по ширине стерео не использовалась. Перекос влево остаётся отдельной задачей; частотная обработка может немного менять измеряемые каналы.

## Использование

1. Загрузить `Diva_Lead_v51_WIP.h2p` в предоставленную Diva.
2. Следом поставить `Diva_Lead_Finish_v51_WIP_x64.dll`: Amount = 1, Output = +1,852506397 dB, PDC включена.
3. MIDI — `Diva_PERFORMANCE_VIDEO_180BPM.mid`, 180 BPM.

Пресет требуется вместе с эффектом. Все 281 параметр Diva, её исходный WAV, MIDI и стадии перед STFT идентичны v50. Бинарник самой Diva не включён. GUI FL Studio не проверялся.

`AB_REFERENCE_V51_WIP_TIMBRE_UPPER_COMPONENTS_AND_DYNAMICS.wav`: оригинал → v51, начало v51 **4,168 с**. Трёхчастный WAV: оригинал → v50 → v51, начала 0 / 4,168 / 8,336 с. Громкость уравнена одним RMS-множителем на фрагмент. Для сравнения используйте WAV. В MP3 проверка прежних допусков не прошла: у v51 изменение баланса R/L достигает 0,029012 dB при границе 0,02 dB, изменение корреляции — 0,011847 при границе 0,01; у оригинала корреляция меняется на 0,010545. Все превышения сохранены в `analysis/mp3_stereo_validation.json`; WAV не имеет этих дополнительных потерь кодирования.

## Проверки и воспроизводимость

Алгоритм сохранён: 638 спектральных значений, 47 состояний усиления, прежние FFT/окна/банки фильтров и PDC 12416 сэмплов при 48 кГц. Изменены значения существующих параметров; новых состояний и расписания исполнения нет. Общий фазовый поворот одинаков для Mid/Side. Стереоцели, явный частотный баланс и стадии перед STFT сохранены v50.

Время реакции выравнивания мощности теперь **1.782497 мс**, ограничение до индивидуального множителя — **6 dB**. Полная независимая цепочка: максимальная ошибка **1.598285154e-07**. Независимая база 197 допустима, поскольку источник и стадии перед STFT сохранены.

Каждый выбранный этап проверен свежим запуском настоящей Diva и настоящим Windows-эффектом. Ошибка ускоренной модели в частной пробе 220 была обнаружена Windows-проверкой 221: взаимодействие двух последовательных матриц учтено неверно. Эту пробу отклонили, модель исправили в 222 и проверили на ненулевых параметрах и Windows-рендере 223. Ошибочная оценка не использована для финального WAV.

Итоговые проверки: два свежих запуска Diva, все 281 параметр и WAV, блоки 47/127/128/511/512/2048, preroll 3/17, 44,1/48/96/192 кГц, сохранение состояния, PDC, каналы, тишина, Amount = 0. Независимо проверяются 12 произвольных входов без MIDI, четыре переходных сигнала, две отдельно включённые поздние группы, масштаб входа и причинность. Допуски сохранены. ZIP проверяется по CRC, всем SHA256 и независимому WAV-расчёту из извлечённых файлов.

Сходимость численного подбора не доказывает глобальную оптимальность или совпадение звука. Различия тембра и стерео остаются. В DSP нет записи оригинала, MIDI, нот или времени исполнения; монтаж сравнения внешний, в `reference_edit.json`. MistaTowa не использовался.

# Проверка: мог ли в оригинале быть эффект?

**Да, лёгкая стереообработка возможна, но конкретный эффект по этой записи не установлен.** У референса каналы L/R заметно различаются, особенно на верхних частотах; у сухого v4 они почти совпадают. Это может быть chorus, другая обработка ширины или различия голосов синтезатора. На результат также влияет HE-AACv2 в исходном видео.

Проверен 81 вариант встроенных Chorus и Plate в настоящем Diva revision 16519. Chorus уменьшает измеримое отличие по ширине, но немного меняет распределение обертонов. По спектру сухой v4 остаётся чуть ближе: в готовом рендере расстояние **0,094 dry → 0,101 chorus**; корреляция каналов **0,999 dry → 0,983 chorus**, у референса **0,921**. Во время подбора у этой настройки получалась корреляция 0,966; chorus модулирует сигнал, поэтому одинаковые крутилки не гарантируют одинаковую фазу эффекта при перезапуске. Это разные измерения, а не процент сходства на слух. FL Studio здесь не запускалась; субъективного прослушивания не было.

Повторное кодирование сухого v4 через FDK HE-AACv2 32 кбит/с изменило корреляцию каналов примерно до 0,995 — в этой проверке кодек не объяснил всю разницу в ширине. Другой энкодер или исходная стереопартия могут дать иной результат. Тишина после фразы в присланной вырезке не позволяет исключить реверберацию: хвост мог быть обрезан.

## Как проверить в FL Studio

Загрузи **`Diva_v4_CHORUS_TEST.h2p`** через браузер PRESETS Diva и используй тот же [MIDI PERFORMANCE](Diva_PERFORMANCE_REFERENCE_180BPM.mid) при **180 BPM**. Это отдельная гипотеза обработки; основной сухой пресет v4 сохранён.

Вручную на сухом v4 меняются только четыре параметра:

| Крутилка | Значение |
|---|---|
| Effect 1 | **On**, модуль **Chorus1** |
| Type | **Ensemble** |
| Depth | **60,00** |
| Wet | **20,00** |

**Rate остаётся 12,00**, как в dry; это значение дисплея Diva, не 12 Гц. **Effect 2 Off**, **Diva ARP Off**. Для более слабой обработки можно уменьшить Wet до 10–15; эти промежуточные значения не являются установленными настройками оригинала.

Пресет проверен после загрузки в свежий экземпляр: остальные параметры совпали с dry, звук конечный, без перегруза. Подробности находятся в [validation.json](validation.json), полный список крутилок — в [TSV](Diva_v4_CHORUS_parameters.tsv).

## Сравнение на одинаковой RMS-громкости

[MP3](AB_reference_v4_DRY_CHORUS.mp3) / [WAV](AB_reference_v4_DRY_CHORUS.wav):

| Начало | Фрагмент |
|---|---|
| **0:00** | Оригинальный референс |
| **0:04,168** | Сухой v4 |
| **0:08,336** | Тот же v4 с Chorus Ensemble |

Начала синхронизированы с вырезкой, между фрагментами по 0,5 с тишины. Выравнивание громкости применяется только к A/B. Отдельный `Diva_v4_CHORUS_TEST.wav` — непосредственный рендер Diva, версия `ALIGNED` добавляет только начальную тишину. Других эффектов в этих рендерах нет.

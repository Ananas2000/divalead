# Diva lead v11 WIP — промежуточный бэкап

**Совпадение ещё не достигнуто.** Продолжение подбора после v10: включена синхронизация OSC2, уточнены настройки настоящего Diva, фиксированный стереофильтр и EQ бокового сигнала. Комплект заново отрендерен из сохранённого H2P с собранной Windows DLL. MistaTowa не использовался. Субъективное прослушивание и проверка в FL Studio здесь не выполнялись.

## Установка

1. Загрузить `Diva_Lead_v11_WIP.h2p` в Diva. FX1 Off; FX2 Plate2 On, Wet 1%; ARP Off.
2. На Insert поставить `Diva_Lead_Finish_v11_WIP_x64.dll`: Amount 100%, Output +1.852506 dB.
3. Импортировать `Diva_PERFORMANCE_VIDEO_180BPM.mid` при 180 BPM с сохранением velocity. VIDEO повторяется через восемь долей. REFERENCE MIDI воспроизводит прежнюю сравнительную последовательность репозитория, с другим интервалом между повторами.
4. Включить компенсацию задержки DAW: DLL сообщает **8320 сэмплов / 173,33 мс при 48 кГц**. Это больше задержки v10 (88 мс); при живой игре задержка заметна. Отдельные 843 сэмпла выравнивания WAV нужны только для сравнения с вырезкой.

Два вида WAV сохранены отдельно:

- `Diva_v11_FINAL_ALIGNED.wav` — последовательность REFERENCE, выровненная для сравнения с прежними версиями; `FINAL_WITH_PDC` содержит задержку DLL, `FINAL` — после её удаления. Название FINAL продолжает схему репозитория и не означает завершённую реконструкцию.
- `Diva_v11_VIDEO.wav` — непрерывный шестисекундный рендер с повтором через восемь долей; `VIDEO_REFERENCE_EDIT` — его копия с явными вырезками исходного референса. `reference_edit.json` хранит границы и отдельные измерения. Нулевой хвост после обрезки — результат монтажа, а не преимущество синтеза.

Исходный WAV состоит из двух фрагментов предоставленного видео: начало первого около 0,494979 с, второго — 3,161333 с. Поэтому пауза между ними не равна исходному интервалу исполнения. Пропущенное промежуточное аудио не добавлено в рендер; его принадлежность к отдельным инструментам не установлена.

`DIVA_ONLY` — Diva с небольшим Plate2 до Finish; `DIVA_DRY` — без FX. A/B WAV/MP3: **оригинал → v10 WIP → v11 WIP**, начала **0:00 / 0:04.168 / 0:08.336**. RMS уравнена по целым фрагментам, отдельные ноты не нормализованы.

Эти числа не являются процентами сходства на слух. Остались различия в атаках, переходах и обертонах.

## Проверки и воспроизведение

Две свежие загрузки сохранённого пресета дают идентичный WAV. H2P округляет FineTune, Tune2 и Resonance; фактические значения сохранены в TSV и `render_timing.json`, а итоговые WAV получены из сохранённого пресета. Windows DLL и независимый DSP совпадают с максимальной ошибкой около 1,5e-8. Проверены блоки 47/127/128/511/512/2048, preroll, state chunk, тишина, Amount 0 и 44,1/48/96/192 кГц; перегруза нет. DLL поддерживает частоты от 8 до 192 кГц.

Исходники и независимый пересчёт — `analysis/`. FIR воспроизводится из сохранённых настроек без WAV оригинала; в DLL нет записи лида, проигрывателя сэмплов или обработки по номеру ноты. Она обрабатывает любой вход. Оригинальный пресет и цепочка эффектов автора остаются неизвестными.

# Diva Lead v6 — уточнение динамики лида

**V6 исправляет измеренные отличия v5 в огибающей и окончании фразы.** Удерживаемая часть ноты в v5 была слишком ровной относительно атаки; верхняя C# оставалась тише референса, а хвост первой фразы был длиннее. Уточнены ADS-огибающая Diva, длительности MIDI и коррекция в Lead Finish. Добавлена мягкая сатурация. Точная исходная цепочка из видео не установлена: это подобранная реконструкция.

## Как загрузить в FL Studio

1. Загрузи **`Diva_Lead_v6.h2p`** через PRESETS самой Diva.
2. Назначь Diva отдельный **Insert**: фейдер **0 dB**, Pan **по центру**, Channel Volume **100%** для сравнения громкости.
3. Положи **`Diva_Lead_Finish_v6_x64.dll`** в свою папку VST2, добавь её в **Options → Manage plugins → Plugin search paths**, запусти **Find installed plugins**.
4. Добавь **Diva Lead Finish v6** в FX-слот Insert с Diva. Его стандартные значения: **Amount 100%, Output +2.33 dB**. Все внутренние настройки уже выставлены.
5. Установи **180 BPM**. Импортируй **`Diva_PERFORMANCE_VIDEO_180BPM.mid`** для повторов как в видео или **`Diva_PERFORMANCE_REFERENCE_180BPM.mid`** для сравнения с вырезкой. В Diva **FX1 Off, FX2 Off, ARP Off**.

При переходе с v5 замени прежний пресет и эффект на v6. Для A/B отключи дополнительную обработку Insert и мастера. Lead Finish v6 — отдельный Windows x64 VST2-эффект, созданный здесь; он не является встроенным эффектом u-he Diva.

## Изменённые крутилки Diva

| ADS ENV 1 | V5 | V6 |
|---|---:|---:|
| Attack | 11,39 | **9,88** |
| Decay | 12,07 | **11,59** |
| Sustain | 100 | **87,83** |
| VEL | 0 | **40** |
| Release | On | **On** |
| KYBD | 0 | **0** |

Это значения дисплея Diva, не миллисекунды. В ADS при Release On длительность отпускания задаёт Decay. Все настройки сохранены в `.h2p`; полный список 281 параметра находится в `Diva_v6_DIVA_parameters.tsv`.

Остальная основа: **Dual VCO / analog1**; VCO1 **Triangle + PWM, 8′, Tune −0,06**; VCO2 **Pulse, 2′, Tune 24,07**; **PW 51,76 / Mix 7,25**; **Ladder 24 dB clean**, **Cutoff 143,99 / Emphasis 12,89 / KYBD 19,86**. Amplifier **Env1, Volume 48,50, Pan −39,33, lin**; Vol Mod **Adder −90** с обоими входами **KeyFollow2**. Режим **poly / last / 3 voices / Stack 1**, Accuracy **great / same**, Fine Tune **−1,13 cents**, TuneSlop **3,27**, OSC Drift **17,46**, Output **119,61**. FM, Sync, Noise, Glide, Vibrato и глубины модуляции pitch/PW/cutoff выключены.

## Партия и длительности

На видео видны **три удерживаемые ноты**, начала **0 / 1½ / 3 доли**, длительности **1½ / 1½ / 1 доля**. Их структура сохранена в `Diva_PATTERN_3notes_VIDEO_180BPM.mid`. Выбранные по аудио MIDI **41 / 37 / 36** отображаются в FL Studio как **F3 / C#3 / C3**. Абсолютные названия клавиш на миниатюре не читаются.

MIDI `PERFORMANCE` разворачивает восемь атак: **F3 → F3 → F4 → C#3 → C#3 → C#4 → C3 → C3**. Арпеджиатор Diva выключен; это реконструкция повторов и октав, а настройки исходного арпеджиатора не прочитаны. Velocity всех нот — **100**. Длительности семи первых атак — **94.94%** от **½ доли**, последней — **78.78%** от **½ доли**. Последняя нота отпускается раньше, чтобы уменьшить хвост.

В VIDEO повтор остаётся через **8 долей**. В REFERENCE — через **6.99137 доли**: небольшая поправка относительно 7 долей совмещает второй повтор с аудиовырезкой. Это поправка к монтажу референса, а не установленная настройка оригинального проекта. Точные значения — в `render_timing.json`.

## Сравнение

`AB_reference_v5_v6.mp3` и WAV содержат одинаковую общую RMS-громкость:

| Начало | Фрагмент |
|---|---|
| **0:00** | Оригинальный референс |
| **0:04,168** | Прежний v5 |
| **0:08,336** | Исправленный v6 |

`Diva_v6_FINAL.wav` — рендер готовой цепочки. `ALIGNED` добавляет **19.48 мс** начальной тишины для совмещения с вырезкой; такую задержку в FL добавлять не нужно. `Diva_v6_DIVA_DRY.wav` содержит только Diva. Атаки, окончание и уровни нот показаны на `comparison.png`.

## Результат проверки

| Измерение — меньшая ошибка лучше | V5 | V6 |
|---|---:|---:|
| Ошибка 24 мс RMS-огибающей | 0.1426 | **0.0892** |
| RMS ошибки уровней 16 нот, dB | 0.418 | **0.246** |
| Лишний хвост 1,337–1,450 с / RMS референса | 0.528 | **0.103** |
| Спектральное расстояние в устойчивых участках | 0.0975 | **0.0928** |
| Спектральное расстояние всего фрагмента | **0.0925** | 0.0957 |
| Взвешенная ошибка обертонов, dB | 3.74 | 3.75 |

Ошибка огибающей снижена примерно на **37%**; это снижение конкретной ошибки, не процент сходства звука. Корреляция L/R в активных участках **0,9223 у оригинала / 0,9223 у v5 / 0,9216 у v6**. Верхняя C# стала ближе по уровню: ошибка **−0,72 / −1,07 dB** в двух фразах v5 уменьшилась до **−0,21 / −0,63 dB** у v6. Остаток есть, особенно во втором повторе. По всему спектру v5 имеет небольшое преимущество; v6 точнее по выбранным показателям динамики.

Исполнены **1264 рендера** при подборе огибающей и дополнительные проверки коррекции. Итог заново загружен в свежий экземпляр настоящего Diva; результат воспроизвёл выбранный вариант. Готовая Windows DLL реально исполнялась под Wine: максимальная погрешность относительно расчётного DSP **1,2 × 10⁻⁷** по амплитуде. Проверены состояние плагина, блоки 512/93, старт после работы в фоне, Amount 0, тишина и частоты 44,1/96 кГц. Перегруза нет.

Сравнение численное; **99% на слух не подтверждены**, прослушивание и запуск FL Studio здесь не выполнялись. Референс вырезан из сжатой записи; его резкое окончание может быть результатом монтажа. Это ограничивает выводы об исходном Release и эффектах. MistaTowa Vol.3 к лиду не относится и в подборе не используется.

Подробные данные — `validation.json`; независимый пересчёт по готовым WAV — `analysis/compare.py`. На GitHub для скачивания отдельного файла нажми **Download raw file**.

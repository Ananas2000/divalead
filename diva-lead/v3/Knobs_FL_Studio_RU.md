# Diva v3: исправление после сравнения с v2

> Архивная версия. После просмотра видео в v4 выделены три удерживаемые ноты и отдельно реконструированы повторные атаки. MIDI этой версии из пяти смен высоты описывал ранний вариант. Актуальная партия и сухой пресет находятся в [инструкции v4](../v4/Knobs_FL_Studio_RU.md).

В v2 действительно оставались расхождения. Подтверждённые проблемы: слишком длинное завершение нот, другое соотношение обертонов и недостаточное движение частоты. V3 исправляет завершение ADS и предлагает другую настройку тембра. Она проверена рендером в присланном Diva revision 16519 под Wine, сохранением пресета и повторной загрузкой. **Совпадение 1:1 и субъективное улучшение не подтверждены**: здесь выполнено численное сравнение WAV, FL Studio не запускалась и прослушивание не проводилось.

## Сравнение

`AB_reference_v2_v3dry_v3stereo.mp3` и одноимённый WAV содержат четыре отрезка:

| Начало | Отрезок |
|---|---|
| 0:00 | Исходный референс |
| 0:04,168 | Предыдущая v2 STEREO — тот самый файл, который ты прислал |
| 0:08,336 | Новая v3 DRY без эффектов |
| 0:12,504 | Новая v3 STEREO со встроенным хорусом |

Громкость отрезков выровнена по общей RMS; между ними паузы по 0,5 секунды. Лимитер не использован. Референс и v2 сохранены без изменений; v3 получена повторной загрузкой окончательных файлов пресетов. `comparison.png` показывает огибающую и спектр первой ноты.

## Что поменять относительно v2

Это числа дисплея Diva, **не герцы и миллисекунды**. Все изменения уже находятся в файлах `.h2p`.

| Параметр | v2 | v3 |
|---|---:|---:|
| PW / Pulse Width | 52,00 | **51,79** |
| MIX / Osc Mix | 10,88 | **7,46** |
| Cutoff | 130,76 | **136,06** |
| Emphasis / Resonance | 7,64 | **10,74** |
| KYBD / KeyFollow | 99,88 | **74,16** |
| ENV 1 Attack | 16 | **20** |
| ENV 1 Release switch | On | **Off** |
| TRIMMERS: `OPT: TuneSlop` | 0 | **38,59** |

**Исправление предыдущей инструкции:** у модели огибающей ADS включённый Release использует время **Decay**. Параметр Release = 4 сохранён внутри состояния плагина, но не задаёт отдельное время завершения этой модели. Поэтому v2 с Decay = 30 оставляла слышимый хвост в паузе. В v3 Release switch выключен; после завершения MIDI-ноты сигнал быстро прекращается.

`OPT: TuneSlop` — вариация настройки осцилляторов во вкладке TRIMMERS. Это отдельный параметр, а не главная ручка Detune VCO 2. В FL Studio его можно найти через **Browse parameters** плагина по имени. Normalized-значение для него — **0,3859**. Настройка использует сохранённые в пресете таблицы вариаций голосов; для воспроизводимости загружай `.h2p` или начинай именно с нашей v2.

## Общие настройки v3

| Блок | Значение |
|---|---|
| Осцилляторы | **Dual VCO**, Shape **analog1** |
| VCO 1 | **Triangle + PWM**, Saw off; Tune **0 / 8′** |
| VCO 2 | **Pulse**; PWM, Triangle, Saw и Sine off; Tune **+24 / 2′** |
| Фильтр | **Ladder / 24 dB / clean** |
| HPF / Feedback | **Feedback / 0** |
| FM, Sync, Noise, Glide, Vibrato, Drift | **0 / Off** |
| Модуляция pitch, PW и cutoff | Глубины **0** |
| ENV 1 | **ADS**, Attack **20**, Decay **30**, Sustain **100**, Release switch **Off** |
| ENV 1 Velocity / KeyFollow | **0 / 0** |
| VCA / Volume | **Env1 / 48,50** |
| Mode / Note Priority / Stack | **mono / last / 1** |
| Accuracy / Offline Accuracy | **great / same** |
| Arpeggiator | **Off** |

**DRY:** оба встроенных эффекта выключены; Pan **0**, верхний Output **137,73**.

**STEREO:** Effect 1 **On → Chorus1 → Classic**, Rate **80**, Depth **90**, Wet **20**; Effect 2 **Off**; Pan **−36,04**; верхний Output **196,25**. Больший Output компенсирует потери уровня обработки и панорамы. В проверенной MIDI-фразе peak около 0,75, ниже 0 dBFS. Стереовариант сохраняет небольшое движение, поэтому его рендеры могут немного отличаться по фазе хоруса.

Полные значения на дисплее и normalized-значения 0…1 находятся в `Diva_v3_DRY_parameters.tsv` и `Diva_v3_STEREO_parameters.tsv`.

## Использование в FL Studio

Загружай `.h2p` через собственный браузер **PRESETS** в Diva: скопируй файл в пользовательскую папку пресетов, открой или обнови браузер. MIDI импортируй в Piano Roll; темп **180 BPM**. Для проверки отключи эффекты канала и мастера. DRY работает без эффектов; у STEREO обработка уже находится внутри Diva.

Ноты FL Studio: **F3 → F4 → C#3 → C#4 → C3**; MIDI **41 → 53 → 37 → 49 → 36**. Длительности **1 → ½ → 1 → ½ → 1 доли**, пауза 3 доли и повтор.

## Проверка и оставшиеся отличия

Все 281 доступных параметра совпали после сохранения и повторной загрузки. В аудио присутствуют 10 нот, нет NaN/Inf и превышения 0 dBFS. Поздняя часть паузы у v3 равна нулю; у присланной v2 её RMS составляла примерно 0,049.

Для v3 сравнивалась энергия в полосах вокруг гармоник, чтобы учитывать расстройку осцилляторов. По этой метрике расхождение снизилось с 3,21 у v2 STEREO до примерно 2,00 у v3 STEREO. **Старая метрика с узкими окнами вокруг точных гармоник у v3 стала хуже**, поскольку часть энергии сдвинулась по частоте. Поэтому эти числа не доказывают, что новая версия на слух лучше. Оба измерения и метод сохранены в `validation.json`.

В референсе остаются иная динамика отдельных нот, дополнительное движение частоты и энергия между гармониками. Начальный fade первой ноты тоже полностью не воспроизведён. V3 следует оценивать как следующую реконструкцию по аудио.

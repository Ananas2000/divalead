# Diva Lead v8 — установка и крутилки

V8 уточняет ширину стерео, спектр, уровни и длительности нот. Используется настоящий Diva rev16519, небольшой встроенный Plate2 и отдельный эффект Lead Finish v8. Это реконструкция: исходный пресет и исходная цепочка из видео не установлены.

## Загрузка в FL Studio

1. Открой **`Diva_Lead_v8.h2p`** в браузере PRESETS самой Diva.
2. Назначь Diva отдельный **Mixer Insert**: фейдер **0 dB**, Pan **по центру**, Channel Volume **100%** для сравнения общей громкости.
3. Добавь папку с **`Diva_Lead_Finish_v8_x64.dll`** в **Options → Manage plugins → Plugin search paths** и запусти **Find installed plugins**. Это Windows x64 VST2 эффект.
4. Добавь **Diva Lead Finish v8** на Insert: **Amount 100%, Output +1.85251 dB**. Значения уже стоят по умолчанию. Эффект показывает два обычных параметра; своего графического окна у него нет.
5. Установи **180 BPM** и импортируй **`Diva_PERFORMANCE_VIDEO_180BPM.mid`**, сохранив velocity. Для сравнения с аудиовырезкой используй **`Diva_PERFORMANCE_REFERENCE_180BPM.mid`**.
6. При переходе с v7 замени **пресет, эффект и MIDI**. Velocity v8: **96 / 96 / 106 / 94 / 97 / 119 / 102 / 101**. Дополнительный swing не нужен: микросмещения и длины уже записаны в MIDI.

В Diva **FX1 Off, FX2 On → Plate2, ARP Off**. Plate2 Wet — **1.00**, то есть **1%**. Не увеличивай его до 100. В Lead Finish сохранены коррекция каналов, общий EQ, мягкая сатурация, стереодобавка верхних частот и коррекция Side-сигнала. Эти настройки подобраны для реконструкции и не доказывают наличие таких эффектов у автора видео.

## MIDI и три ноты с видео

Восемь слышимых атак: **F3 F3 F4 C#3 C#3 C#4 C3 C3** в обозначениях FL Studio, MIDI **41 41 53 37 37 49 36 36**. Шаг — половина доли. Gate первых семи нот **0.951842**, последней **0.800000** от шага; точные смещения и длины — `render_timing.json` и MIDI. VIDEO повторяет фразу через **8 долей**, REFERENCE через **6.991366 доли**, учитывая монтаж вырезки.

На видео видны **три удерживаемые ноты длиной 1½ → 1½ → 1 доля**. Их отдельный MIDI — `Diva_PATTERN_3notes_VIDEO_180BPM.mid`, иллюстрация — `Video_pattern_3_notes.png`. Высоты для реконструкции определены по аудио: подписи клавиш на видео не читаются достаточно точно.

Проверен способ получить нужную последовательность высот из трёх нот внутри Diva: **ARP On, Direction up+dn 2, Octaves 2, Clock 1/8, Multiply 1x, Progression serial или round**. Это подтверждённый способ генерации, а не доказательство настроек автора. Испытанный вариант со встроенным ARP хуже совпал по атакам и устойчивому тембру, поэтому основной v8 использует восемь отдельных событий `PERFORMANCE` и **ARP Off**. Не включай ARP поверх MIDI PERFORMANCE.

MistaTowa Vol.3 — отдельный звук, к этому лиду не добавлен.

## Аудио и A/B

- **`Diva_v8_FINAL.wav`** — исполненная цепочка с первого MIDI события.
- **`Diva_v8_FINAL_ALIGNED.wav`** — тот же результат, сдвинутый на **843 сэмпла / 17.562 мс** для сравнения с вырезкой. Добавлять эту задержку в FL Studio не нужно.
- **`Diva_v8_DIVA_ONLY.wav`** — выход Diva с включённым Plate2, до Lead Finish.
- **`Diva_v8_DIVA_DRY.wav`** — Diva с FX1/FX2 Off, до Lead Finish. Для этого варианта выключи встроенный FX2 и отдельный FX-слот.
- **`AB_reference_v7_v8.wav` / `.mp3`** — **оригинал → v7 → v8**, начала **0:00.000 / 0:04.168 / 0:08.336**. Между фрагментами 0,5 с тишины; RMS уравнена по целым фрагментам, без нормализации отдельных нот. Измерения выполнены по WAV.

Корреляция L/R в активных участках: **референс 0,9223 / v7 0.9397 / v8 0.9231**. V8 ближе по ширине стерео, уровням нот, огибающей и приведённым спектральным измерениям. **Фазовая ошибка обертонов немного больше, чем у v7.** Первая атака и короткие переходы между нотами ещё отличаются. Эти числа не являются процентом сходства на слух.

Два свежих экземпляра Diva дали одинаковый float WAV. Windows DLL действительно исполнена под Wine и совпала с расчётным DSP с максимальной погрешностью **6e-08**. Проверены состояние, блоки 512/93, запуск после фоновой работы, Amount 0, тишина, 44,1/96 кГц и отсутствие перегруза. FL Studio и субъективное прослушивание здесь не выполнялись. **Полное совпадение и 99% на слух не подтверждены.**

`analysis/compare.py` пересчитывает измерения без плагинов; подробности — `validation.json`, настройки — `Finish_settings.json`, график — `comparison.png`. Для отдельного файла на GitHub нажми **Download raw file**.

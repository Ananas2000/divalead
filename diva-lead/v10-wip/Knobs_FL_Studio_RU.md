# Diva lead v10 WIP — промежуточный бэкап

Продолжение подбора после v8 и v9. **Совпадение с оригиналом ещё не достигнуто.** WAV исполнен настоящим Diva rev16519 из сохранённого H2P, затем обработан собранной Windows DLL под Wine. MistaTowa не использовался. Исходные пресет и эффекты автора не установлены; субъективное прослушивание и FL Studio здесь не выполнялись.

В v10 уточнены общая фаза и EQ, transient shaper, интервалы отпускания и небольшие смещения атак MIDI. Крутилки Diva и обработка проверены повторным рендером сохранённого комплекта. В эффекте нет аудиозаписи лида, проигрывателя сэмплов или коррекции по номеру ноты: его FIR и остальные фильтры обрабатывают любой вход.

## Установка и сравнение

1. Загрузить `Diva_Lead_v10_WIP.h2p` в Diva. FX1 Off, FX2 Plate2 On с Wet 1%; ARP Off.
2. На Insert поставить `Diva_Lead_Finish_v10_WIP_x64.dll`: Amount 100%, Output +1.852506 dB.
3. Темп 180 BPM, новый MIDI `Diva_PERFORMANCE_VIDEO_180BPM.mid`, velocity сохранить. Для исходной вырезки использовать REFERENCE MIDI. Три удерживаемые ноты с видео сохранены отдельно; встроенный ARP при проверке дал худшую динамику.
4. Использовать компенсацию задержки DAW. Эффект сообщает **4224 сэмпла / 88 мс при 48 кГц**; при другой частоте задержка меняется. Не добавлять этот сдвиг вручную поверх компенсации.

`Diva_v10_FINAL_WITH_PDC.wav` — сырой вывод с задержкой; `Diva_v10_FINAL.wav` — после её удаления; `Diva_v10_FINAL_ALIGNED.wav` дополнительно сдвинут на 843 сэмпла для сравнения с вырезкой. Этот дополнительный сдвиг не нужен при игре в FL Studio. Файлы FINAL именованы по принятой в репозитории схеме; **название не означает, что реконструкция окончательная**. DIVA_ONLY — Diva с небольшим Plate2 до отдельного эффекта; DIVA_DRY — без FX. Все параметры свежей загрузки сохранены в TSV.

A/B WAV/MP3: **оригинал → v9 WIP → v10 WIP**, начала **0:00 / 0:04.168 / 0:08.336**. RMS уравнена по целым фрагментам, отдельные ноты не нормализованы. Измерения сделаны по WAV.

V10 заметно ближе по огибающей, уровням нот и измерению ширины в пяти полосах; хвост короче. V9 сохраняет небольшое преимущество по взвешенной спектральной ошибке и фазе L/R. Эти числа не являются процентами сходства на слух.

Атаки повторяющихся нот, переходы между октавами, остаточные обертоны и фаза всё ещё различаются. Бэкап фиксирует полезное улучшение, не подтверждает точное совпадение.

## Проверки

Две свежие загрузки H2P дали идентичный WAV. Проверены Windows DLL и независимый расчёт DSP, state chunk, размеры блока 47/127/128/511/512/2048, preroll, тишина, Amount 0 и 44,1/48/96 кГц; перегруза нет. Коэффициенты FIR воспроизводятся из сохранённых настроек без исходного аудио. Детали — `validation.json`, независимые измерения — `analysis/compare.py`.

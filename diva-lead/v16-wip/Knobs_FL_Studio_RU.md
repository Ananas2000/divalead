# Diva lead v16 — промежуточный бэкап

**Совпадение ещё не достигнуто.** Пресет Diva и MIDI совпадают с v15. В Finish добавлены три динамические EQ-полосы: их усиление зависит от отношения энергии полосы к энергии входящего стереосигнала. Слабая составляющая получает коррекцию, а сильная основная частота в той же полосе затрагивается меньше. Затем применена небольшая коррекция Side. Записи референса и расписания нот внутри эффекта нет. MistaTowa не использовался.

1. Загрузить Diva_Lead_v16_WIP.h2p в свою Diva. Его параметры идентичны v15.
2. После Diva поставить Diva_Lead_Finish_v16_WIP_x64.dll, Windows VST2 x64: Amount = 100%, Output = +1,85251 dB.
3. Импортировать Diva_PERFORMANCE_VIDEO_180BPM.mid при 180 BPM, сохранив velocity. Короткое исполнение REFERENCE хранится отдельно.
4. Включить компенсацию задержки DAW: 8320 сэмплов / 173,33 мс при 48 кГц. Смещение WAV на 819 сэмплов применяется только при сравнении с оригиналом.

A/B: **оригинал → v15 → v16**, RMS уравнена по целым фрагментам. VIDEO_REFERENCE_EDIT содержит вырезки непрерывного исполнения, REFERENCE_PATTERN — отдельный короткий рендер. WAV — PCM24; MP3 служит копией для прослушивания. DIVA_ONLY — пресет до Finish, DIVA_DRY — Diva без встроенных FX. VIDEO_DIVA_ONLY — полный шестисекундный вход, VIDEO — обработка без задержки, WITH_PDC сохраняет сообщаемую задержку. FINAL в именах следует прошлым версиям и не означает готового совпадения.

Непрерывное исполнение, одинаковые вырезки, меньшая ошибка лучше:

| Измерение | v15 | v16 |
|---|---:|---:|
| Спектральная ошибка, dB | 2.752742 | 2.717456 |
| Спектр всего фрагмента | 0.083733 | 0.081137 |
| Разброс уровней FFT-окон, dB | 0.113257 | 0.121569 |
| Огибающая 12 мс | 0.121071 | 0.118378 |
| Огибающая 24 мс | 0.072485 | 0.068300 |
| Уровни нот, dB | 0.084133 | 0.080598 |
| Фаза L/R, градусы | 3.964084 | 3.865596 |
| Баланс L/R, dB | 1.079910 | 1.030452 |
| Корреляции пяти полос | 0.000003280 | 0.000008784 |

Улучшились спектр, обе огибающие, уровни нот, фаза и баланс. Разброс уровней FFT-окон вырос с 0,113257 до 0,121569 dB. Ошибки корреляций пяти полос и когерентности чуть выше v15; эти величины малы. Полные результаты и отдельное короткое исполнение находятся в validation.json. Эти измерения не являются процентами сходства на слух. Спектр обертонов и переходы между нотами ещё различаются. Прослушивание и проверка в FL Studio здесь не выполнялись.

Начало второй вырезки захватывает предыдущий звучащий фрагмент видео. Полное сравнение сохраняет этот участок. Его источник не подменён дополнительным сэмплом. Нулевой хвост VIDEO_REFERENCE_EDIT получается от монтажа, а не от улучшения синтезатора. Предыдущие WAV v15 для сравнения побитно идентичны опубликованным файлам.

Проверены два свежих запуска настоящей Diva, реальные Windows-рендеры, расчёт, размеры блоков, преролл, 44,1/48/96/192 кГц, тишина, Amount 0, VST chunk и прохождение между каналами. Задержка и восемь FIR-путей прежние. Все 131072 коэффициента FIR, 19 динамических параметров и 5 новых Side-gain воспроизводятся побитно из JSON без аудио. Исходники и независимые измерения находятся в analysis/.

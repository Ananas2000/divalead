# Diva lead v9 WIP — промежуточный бэкап

Это продолжение подбора после v8, **не окончательная реконструкция**. Реальный Diva загружает сохранённый H2P; WAV получен рендером Diva и скомпилированным Windows x64 эффектом под Wine. Сэмпл MistaTowa не использовался. Исходная цепочка автора не установлена; FL Studio и субъективное прослушивание здесь не проверялись.

В v9 уточнены крутилки Diva и обработка стерео. К цепочке v8 добавлен общий для любого входного сигнала FIR EQ/phase, работающий через блочную свёртку. В эффекте нет записи лида, проигрывателя сэмпла или обработки, выбираемой по номеру ноты. Стационарные коэффициенты описывают частотную характеристику. Остались различия атак, переходов, спектра и фазы; численные улучшения не являются процентами сходства на слух.

## В FL Studio

1. Загрузить `Diva_Lead_v9_WIP.h2p` в Diva. FX1 Off, FX2 Plate2 On; ARP Off.
2. На Insert загрузить `Diva_Lead_Finish_v9_WIP_x64.dll`: Amount 100%, Output +1.852506 dB.
3. Темп 180 BPM; импортировать `Diva_PERFORMANCE_VIDEO_180BPM.mid`, сохранив velocity. Для сравнения с вырезкой использовать REFERENCE MIDI. Три удерживаемые ноты из видео сохранены отдельно; основной пресет использует восемь атак, без ARP.
4. Эффект сообщает хосту задержку **4224 сэмпла / 88 мс при 48 кГц**. Использовать автоматическую компенсацию задержки FL Studio. При других частотах задержка меняется; не добавлять 88 мс вручную поверх компенсации. Текущий плагин имеет собственный VST ID.

`Diva_v9_FINAL_WITH_PDC.wav` — сырой вывод хоста с задержкой. `Diva_v9_FINAL.wav` — после её удаления; `Diva_v9_FINAL_ALIGNED.wav` дополнительно сдвинут на 843 сэмпла для сопоставления с вырезкой. Этот сдвиг не нужен в FL Studio. `Diva_v9_DIVA_ONLY.wav` — Diva до отдельного эффекта. Все крутилки свежей загрузки — `Diva_v9_DIVA_parameters.tsv`.

## Проверки

Две свежие загрузки сохранённого H2P дали одинаковый WAV. Windows DLL проверена независимым расчётом DSP, блоками 47/127/128/511/512/2048, запуском с preroll, тишиной, Amount 0 и частотами 44,1/48/96 кГц. State chunk roundtrip прошёл. Максимальный уровень ниже 0 dBFS. Подробности — `validation.json`; пересчёт измерений — `analysis/compare.py`.

Следующий подбор должен уточнить атаки и переходы, остаточный спектр и фазу. Этот комплект сохраняет достигнутое улучшение и не подтверждает полное совпадение с оригиналом.

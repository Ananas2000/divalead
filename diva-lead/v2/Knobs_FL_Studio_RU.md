# Diva: настройки версии 2

> Архивная версия. После просмотра видео в v4 выделены три удерживаемые ноты и отдельно реконструированы повторные атаки. MIDI этой версии из пяти смен высоты описывал ранний вариант. Актуальная партия и сухой пресет находятся в [инструкции v4](../v4/Knobs_FL_Studio_RU.md).

**Поправка после следующего сравнения:** у ADS включённый Release использует время Decay. Число Release = 4 в сохранённом состоянии не задаёт отдельный хвост этой модели; v2 продолжает звучать в паузе. Это исправлено в [версии 3](../v3/Knobs_FL_Studio_RU.md), вместе с новой настройкой тембра. Значения ниже описывают прежний файл v2.

Для сухого звука загрузи **Diva_Lead_Reference_v2_DRY.h2p**. Эта версия подобрана с рендером присланного тобой Diva, revision 16519, через Windows VST-хост под Wine. FL Studio в облаке не запускалась. Оба файла пресета сохранены самим движком Diva, повторно загружены и проверены по параметрам и аудиорендеру.

По сравнению с v1 уменьшен второй осциллятор, шире открыт фильтр, добавлен небольшой attack и включён mono. Это реконструкция по аудио, а не найденный оригинальный пресет автора. Совпадение 1:1 не подтверждено.

## Загрузка в FL Studio

1. Открой свою Diva и её вкладку **PRESETS**. Через контекстное меню пользовательской папки открой её в Проводнике.
2. Скопируй туда `.h2p`, обнови браузер пресетов и выбери **Diva_Lead_Reference_v2_DRY**. Файл загружается через Diva, а не как `.fst` в меню FL Studio.
3. Импортируй **Lead_reference_180BPM.mid** в Piano Roll канала Diva и установи **180 BPM**. MIDI содержит обе фразы и паузу между ними.
4. Для сравнения сухого звука отключи обработку канала и мастера, включая лимитер. Сравнивай при одинаковой громкости.

## Отдельный стереовариант

**Diva_Lead_Reference_v2_STEREO.h2p** использует тот же синтез и встроенный хорус. Он предназначен для сравнения с шириной исходного WAV. Внешние эффекты FL Studio для него не нужны.

| Параметр | Значение |
|---|---|
| Effect 1 | **On → Chorus1 → Classic** |
| Rate / Depth / Wet | **12 / 40 / 28** |
| Effect 2 | **Off** |
| Amplifier Pan | **−38,67** |
| Верхний Output | **164,69** |

Панорама подогнана под баланс исходного файла: его левый канал примерно на 2,9 dB громче правого. Число Pan относится к Diva; такое же число в ручке панорамы FL Studio может дать другой баланс. Небольшие различия между повторными стереорендерами ожидаемы из-за фазы модуляции хоруса.

## Аудиосравнение

В **AB_reference_dry_stereo.mp3** и одноимённом WAV три отрезка с паузами по 0,5 секунды:

1. **0:00** — исходный референс.
2. **0:04,168** — новая Diva без эффектов.
3. **0:08,336** — новая Diva со встроенным хорусом.

Общая RMS-громкость отрезков выровнена; лимитер не использован. Отдельные `Diva_v2_DRY.wav` и `Diva_v2_STEREO.wav` — рендеры непосредственно сохранённых и повторно загруженных пресетов, 48 kHz, stereo, float32. Они позволяют сравнить этот движок с твоей Diva в FL Studio.

## Что проверено

В обоих рендерах присутствуют все 10 MIDI-нот, нет NaN/Inf и перегруза выше 0 dBFS. Основные параметры после сохранения и загрузки совпали. Сравнение гармоник на шести участках нот даёт ошибку около **3,95** для сухой v2 против **16,39** для v1 по используемой метрике. Это численный показатель спектрального сравнения, а не процент сходства и не замена прослушиванию. Подробности и измерения лежат в `validation.json`.

В Piano Roll FL Studio фраза — **F3 → F4 → C#3 → C#4 → C3** (MIDI 41 → 53 → 37 → 49 → 36). Длительности: **1 → ½ → 1 → ½ → 1 доли**. Затем пауза 3 доли и повтор. MIDI исключает путаницу с обозначениями октав.

# Diva Lead v81 WIP — три удерживаемые ноты

Относительно v80 изменён параметр Diva Plate2 Damp: 72,00 → 68,00. Остальные 280 параметров, трёхнотный MIDI, ARP и огибающие прежние. Использована заново построенная независимая NEW-база и отдельный fixture именно этого источника. Ошибка тембра снизилась; отдельные метрики могут стать хуже, смотри таблицу сравнения.

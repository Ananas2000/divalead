# Diva lead v18 — промежуточный бэкап

**Совпадение ещё не достигнуто.** v18 уточняет velocity и длительности двух фраз MIDI отдельно. Параметры самой Diva сохранены из v17. В Finish добавлена небольшая коррекция второй гармоники от входящего сигнала. Это общий резонатор и квадратичный возбудитель; записи референса, таблицы нот и расписания MIDI внутри эффекта нет. Фильтры, пять динамических полос, четыре коррекции Side и задержка прежние. MistaTowa исключён.

1. Загрузить Diva_Lead_v18_WIP.h2p в свою Diva.
2. После Diva поставить Diva_Lead_Finish_v18_WIP_x64.dll: Windows VST2 x64, Amount 100%, Output +1,85251 dB.
3. Импортировать Diva_PERFORMANCE_VIDEO_180BPM.mid при 180 BPM с сохранением velocity. У второго прохода свои velocity и gate; интервал остаётся 8 долей. Дополнительный MIDI REFERENCE сохраняет короткий протокол v17 с интервалом 7 долей: он проверяет изменение обработки при прежнем исполнении.
4. Включить компенсацию задержки DAW: 8320 сэмплов / 173,33 мс при 48 кГц. Совмещение WAV с оригиналом использует прежние 819 сэмплов.

A/B: **оригинал → v17 → v18**, RMS уравнена по целым фрагментам. Основной файл — AB_reference_v17_v18_WIP_VIDEO_REFERENCE_EDIT.wav; MP3 — копия для прослушивания. REFERENCE_PATTERN проверяет отдельный короткий протокол. DIVA_ONLY — пресет до Finish, DIVA_DRY — Diva без встроенных FX, VIDEO_DIVA_ONLY — полный шестисекундный вход. WITH_PDC сохраняет задержку, VIDEO её удаляет. FINAL в именах следует прежним версиям и не означает готового совпадения.

Проверены два свежих запуска сохранённого H2P в настоящей Diva, Windows DLL, native-сборка и независимый расчёт, блоки, преролл, 44,1/48/96/192 кГц, тишина, Amount 0, VST chunk и прохождение между каналами. 131072 FIR-коэффициента, 69 динамических/Side-констант и 6 констант возбудителя воспроизводятся из JSON без аудио.

# Diva Lead v57 WIP — загрузка в FL Studio

Комплект для **FL Studio 64-bit под Windows**. Это новый промежуточный результат после WIP005: совпадение с оригиналом ещё неполное. В звук входят пресет Diva и наш эффект Finish. Используй файлы одной версии.

## Быстро загрузить готовый звук

1. Распакуй ZIP целиком. Открой пустой проект FL Studio, поставь **180 BPM** и **48 000 Hz** в Audio settings.
2. Перетащи `Diva_Lead_v57_REFERENCE_EDIT.wav` в **Playlist**. Это наш фрагмент из A/B, с той же громкостью, уже с обработкой.
3. В настройках Audio Clip оставь **Normalize выключенным**, Pitch = 0, Time stretching → **Resample**, ручку Time сбрось через Reset. Не применяй Fit to tempo. Канальная громкость — **0 dB**, панорама по центру.
4. Направь клип на свободный трек микшера без эффектов. Фейдеры этого трека и Master — **0 dB**; для сравнения отключи мастер-лимитер и прочую мастер-обработку.
5. Для целой исполненной партии вместо короткого фрагмента возьми `Diva_Lead_v57_FULL_180BPM.wav`. В нём два прохода партии и хвост, всего 6 секунд. Он сохранён на рабочем уровне эффекта; короткий сравнительный фрагмент отдельно выровнен по общей громкости с референсом.

На готовый WAV повторно ставить Finish не нужно: обработка уже записана в файл.

`AB_REFERENCE_V57_WIP.wav` — **оригинал → пауза → v57**, v57 начинается с **4,168 с**. Это файл для сравнения, а не MIDI-партия.

## Установить эффект Finish

1. Скопируй `Diva_Lead_Finish_v57_WIP_x64.dll` в свою папку **VST2 64-bit**. Например: `C:\VST64\DivaLead\`. Сам плагин не требует соседних файлов или установки Python.
2. В FL Studio открой **Options → Manage plugins**. Добавь эту папку в **Plugin search paths**, затем нажми **Find installed plugins**.
3. Найди **Diva Lead Finish v57 WIP** и добавь его в избранное. Это **эффект микшера**, не генератор Channel Rack. У v57 отдельный ID: старый v53 заменять не нужно.
4. На нужном Insert микшера выбери его через меню слота эффектов. Mix самого слота — **100%**, слот включён.
5. Параметры уже выставлены по умолчанию: **Amount = 100%**, **Output ≈ +1,85 dB** (расчётное значение +1,852506397 dB). У эффекта два параметра и стандартное представление средствами хоста; отдельного нарисованного интерфейса у него нет.
6. Оставь автоматическую компенсацию задержки **PDC** включённой. При 48 kHz эффект сообщает **12 416 сэмплов** задержки. Вручную сдвигать дорожку на эту величину не нужно. Такая задержка ощутима при игре с клавиатуры; записанные ноты/аудио воспроизводятся с PDC.

`Diva_Lead_Finish_v57_WIP.fxp` — дополнительная VST2-программа с этими двумя параметрами. Для первого запуска она не нужна: значения уже зашиты в начальное состояние DLL. Если загружаешь её, используй загрузку VST-программы в Wrapper, а не браузер пресетов Diva.

## Воспроизвести точную исходную цепочку без настройки синтезатора

Этот способ использует именно тот сырой рендер Diva, на котором проверялась версия.

1. Перетащи **`Diva_SOURCE_FROZEN_48k.wav`** в Playlist с начала такта. Темп — 180 BPM, Audio settings — 48 kHz.
2. Для Audio Clip: Normalize выключен, Pitch = 0, Time stretching → Resample, Time → Reset, **без Fit to tempo**. Канальная громкость — 0 dB, панорама по центру, Stereo separation — исходное положение.
3. Назначь клипу отдельный Insert микшера. Оставь на нём **только Finish v57**, с настройками выше. Фейдер Insert — 0 dB. Master — 0 dB и без дополнительной обработки.
4. Начинай воспроизведение с начала клипа, а не с середины. Сравни с `Diva_Lead_v57_FULL_180BPM.wav` на другой чистой дорожке, включая дорожки по очереди.

Замороженный исходник уже содержит звук Diva, но **ещё не содержит Finish**. Готовый FULL-WAV содержит оба этапа. Не отправляй обе дорожки одновременно в один и тот же эффект. Уровень до Finish важен для его адаптивной обработки.

## Играть свои ноты через Diva

1. Добавь свою установленную **u-he Diva** в Channel Rack. Сама Diva в архив не включена.
2. В собственном браузере **PRESETS** Diva открой папку пользовательских пресетов через её контекстное меню. Скопируй туда `Diva_Lead_v57_WIP.h2p`, обнови список и загрузи пресет. `.h2p` открывается в Diva, это не `.fst` для меню FL Studio.
3. Через **Piano Roll → File → Import MIDI file** импортируй `Diva_PERFORMANCE_180BPM.mid` в канал Diva. Установи 180 BPM, сохрани velocity и микросдвиги нот; не применяй Quantize. В файле 16 нот, две группы по 8; номера MIDI: `41, 41, 53, 37, 37, 49, 36, 36`, затем повтор. Номера надёжнее названий октав, которые различаются в программах.
4. Громкость канала Diva в Channel Rack выставь в **0 dB**, панораму — по центру. Направь Diva на отдельный Insert и поставь **Finish v57** первым и единственным эффектом. Mix слота — 100%, Amount — 100%, Output — +1,85 dB. Фейдер Insert — 0 dB, Master без дополнительной обработки.
5. Оставь параметры самого пресета, в том числе настройки голосов и встроенных эффектов. Дай Diva обработать немного тишины после загрузки, затем запусти партию с начала. Для экспорта используй WAV 48 kHz, без нормализации и с хвостом.
6. Сохрани свой проект обычным **File → Save as** в `.flp` — вместе с выбранными экземплярами Diva и Finish.

В проверенном рендере Diva перед нотами обрабатывала **128 блоков тишины по 512 сэмплов**, затем получала MIDI-reset и ещё один блок. В FL Studio эта внутренняя история зависит от запуска/буфера/версии Diva, поэтому один пресет не гарантирует побитовое повторение источника. Кроме того, FL может округлить импортированный MIDI под timebase проекта. Для точного воспроизведения опубликованного WIP используй готовый WAV либо замороженный исходник с Finish. Живой вариант нужен для игры и редактирования нот.

## Если что-то не загрузилось

- **Finish не находится:** проверь x64 FL Studio, путь VST2 и повторное сканирование. Нужен файл `.dll`, а не его ZIP или исходник `.c`.
- **Звук другой по уровню/тембру:** сначала проверь канал перед Finish, фейдеры, Mix слота, мастер-лимитер, Normalize и растяжение Audio Clip. Затем сравни замороженный исходник через Finish с готовым FULL-WAV.
- **Ищешь текущую версию в старых инструкциях:** для этого комплекта используй именно эту инструкцию, пресет и DLL v57. Старые настройки chorus/EQ/pan из ранних версий поверх v57 не добавляются.

Проверены загрузка DLL настоящим Windows VST2-хостом под Wine, звук относительно выбранного рендера, начальные параметры, сохранение/загрузка состояния, разные размеры блоков и независимые DSP-проверки. **GUI самого FL Studio в этой среде не запускался.** Технические результаты находятся в `verification/`.

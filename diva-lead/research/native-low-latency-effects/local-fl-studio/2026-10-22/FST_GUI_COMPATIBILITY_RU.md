# Исправление FST по реальной FL Studio 20.0.3

22 октября 2026, локальная Windows, FL Studio 20.0.3 build 532 x64.

Облачный `01_SOURCE.fst` из checkpoint-WIP загружал только последний
Stereo Shaper во второй слот. Наличие 4 plugin events при независимом
чтении контейнера не подтверждало правильную загрузку FL.

Для контроля добавлен родной WaveShaper и сохранён микшерный FST самой FL:
`GUI_TWO_EFFECTS_REFERENCE.fst`. Он содержит WaveShaper в слоте 1 и
Stereo Shaper в слоте 2 и повторно загружается правильно.

Найдены две ошибки облачного генератора:

- Event 98 завершает блок слота; в исходном генераторе он стоял перед ним.
- DWORD по смещению 4 внутри event 212 должен соответствовать индексу
  слота (0, 1, 2, ...). Исходный генератор записывал 1 во всех блоках.
  Одной перестановки event 98 оказалось недостаточно.

Исправленные пресеты построены по оболочке реального экспорта FL 20.0.3.
Все 12 native DSP payloads event 213 сохранены без изменения байтов.
Отдельный контроль: родной FST с заменой только состояния WaveShaper
на облачное также успешно загрузился. Сам payload WaveShaper не был причиной.

Визуально проверена загрузка всех дорожек:

| Дорожка | Эффекты по порядку |
| --- | --- |
| SOURCE | WaveShaper, Chorus, Stereo Shaper, Stereo Shaper |
| MID | Stereo Shaper, Parametric EQ 2, Parametric EQ 2 |
| SIDE | Stereo Shaper, Parametric EQ 2, Parametric EQ 2, Stereo Shaper |
| SUM | Stereo Shaper |

Дорожечные пресеты не содержат маршрутизацию. Её необходимо проверить
в реальном FLP: SOURCE только MID/SIDE; MID и SIDE только SUM; SUM только Master.
Генератор задаёт Chorus mix слота 4923/12800 = 38.4609375%; фактическое
сохранённое значение и остальные параметры ещё требуют проверки FLP.

Это исправление переноса и загрузки. Свежего аудиорендера на момент этой
записи ещё нет; близость тембра к оригиналу и суммарная задержка не подтверждены.
Канонический облачный checkpoint оставлен для воспроизводимости.

Код: `../tools/repair_mixer_fst.py`, исходный парсер `../tools/cloud_native_fst.py`.
В комплекте совместимые FST и контрольный экспорт самой FL.

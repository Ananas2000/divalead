# Перенос обработки Diva на штатные эффекты FL Studio

По просьбе пользователя следующая задача — убрать большую задержку при игре
нотами и перенести обработку на штатные эффекты. Трёхнотный источник Diva
сохраняется. Подбор через старый Finish приостановлен на границе между заданиями;
все законченные версии и лучший проверенный результат сохранены.

В опубликованном v83 Finish задержка составляет 12416 сэмплов при 48 кГц,
то есть 258,67 мс. Компенсация задержки в проекте не устраняет её при игре
с клавиатуры в реальном времени.

## Какие файлы ещё нужны

| Файл | Для чего |
| --- | --- |
| `Fruity Chorus_x64.dll` | Модулированные короткие задержки: в Finish есть трёхголосная chorus-обработка. |
| `Fruity Stereo Shaper_x64.dll` | Матрица каналов, выделение центра/боковой составляющей и управление стерео. |
| `QuickFontCache_x64.dll` | Служебная библиотека из `Shared` установки FL Studio. Её отсутствие уже подтверждено при реальном запуске. |

Эффекторы лучше брать из той же установки FL Studio, что и уже присланные DLL.
Если точное расположение QuickFontCache отличается, достаточно поиска этого
имени в каталоге установленной FL Studio.

## Что проверено

Все восемь присланных файлов — 64-битные PE DLL с экспортом
`CreatePlugInstance`. Это родной интерфейс плагинов FL Studio. Входа
`VSTPluginMain` у них нет; существующий хост для Diva/VST2 здесь неприменим.
В `diagnostics/DLL_INSPECTION.json` сохранены SHA256, размеры и импорты.
Присланные проприетарные DLL в GitHub не включены.

Собран предварительный Win64 хост для проверки интерфейса FL.
Первый запуск Soft Clipper без графической среды завершился ошибкой загрузки
998. После настройки виртуального экрана плагин показал окно
`QuickFontCache DLL not found!`. Журнал загрузчика установил точное имя:
`QuickFontCache_x64.dll`, ошибка `c0000135`.
Повторный журнал с проверенным пакетом Xvfb подтвердил ту же ошибку поиска
библиотеки. Пакет Xvfb проверен по SHA256 из индекса Debian с проверенной
подписью InRelease. Снимок окна относится к первому запуску с виртуальным
экраном; в повторном снимке окно не успело отобразиться. Подтверждением
повторного запуска служит журнал загрузчика.
Весь интерфейс FL Studio не запускался.

Выполнение до `CreatePlugInstance`, обработки аудио и сохранения состояния
пока не дошло. Совместимость самодельного проверочного хоста с этими DLL ещё
не подтверждена. Готовых штатных пресетов и нового проверенного WAV пока нет.

## Состав обработки для переноса

| Обработка в Finish | Доступный или недостающий штатный инструмент |
| --- | --- |
| Частотный баланс, общий и раздельный для каналов/центра/боковой составляющей | Parametric EQ 2, несколько экземпляров при необходимости; Stereo Shaper и маршрутизация микшера |
| Нелинейная окраска и мягкое ограничение | WaveShaper; Soft Clipper или Blood Overdrive только по результатам сравнения |
| Короткие модулированные задержки, отдельная доля в центре и по краям | Дополнительный Fruity Chorus с маршрутизацией |
| Контроль динамики | Уже присланный Maximus, с измерением фактической задержки выбранного режима |
| Реверберация | Сохраняется Plate2 в исходном Diva; присланный Reeverb доступен для проверки при необходимости |
| Коррекция гармоник, зависящая от текущей высоты и спектра, и частотная фазовая коррекция | Требуют нового подбора и проверки; статический EQ не воспроизводит автоматически весь алгоритм Finish |

Pitcher в предполагаемую цепочку не включается: источник уже даёт нужное
движение высоты с тремя удерживаемыми нотами и внутренним ARP Diva.
Не требуется включать все присланные плагины подряд. После устранения
зависимости нужно измерить реальную задержку и сравнивать реальные рендеры
с исходным референсом и сохранённым результатом. Совпадение пока не достигнуто.

## Продолжение в облаке

Исходники проверочного хоста и проверка Debian-пакета находятся в `scripts`.
Для запуска использовать отдельную рабочую папку `/tmp/divalead-native-effects`
и отдельный Wine prefix, не трогая рабочий prefix Diva.
Проверочный хост собран имеющимся компилятором:

```bash
/workspace/divalead-setup/sysroot/usr/bin/x86_64-w64-mingw32-gcc-posix \
  -O2 -o /tmp/divalead-native-effects/fl_native_probe.exe \
  /tmp/divalead-native-effects/fl_native_probe.c -lole32 -luuid -lm
```

В скрипте `verify_xvfb_package.py` проверяются подпись Debian InRelease,
SHA256 индекса и SHA256 самого пакета. После проверки пакет можно извлечь
через `dpkg-deb -x` в эту же временную рабочую папку. Существующая система
содержит требуемые библиотеки X11 и libXfont2.
Предварительное описание интерфейса FL сверено с открытым
[fpsdk](https://github.com/tonikasoft/fpsdk/tree/master/src/cxx).
Неизвестные запросы хоста и проверка лицензии не реализованы и возвращают 0;
успешная авторизация, работа аудио и перенос состояния не заявляются.

`native-effects-priority.json` блокирует автоматический запуск старых трёх
Finish-подборщиков. Обновлённый `start_three_services.py` дважды проверен:
обоим запускам соответствует режим переноса, новые подборщики не запускаются.
До готовности и проверки штатной цепочки этот приоритет сохраняется.

# Продолжение подбора Diva в локальной FL Studio 20

Это передача текущего состояния из облачного сеанса, а не подтверждение
доступа к компьютеру пользователя. Дата: 22 октября 2026 года.

## Сначала проверить фактический доступ

В исходном чате доступны только облачный Linux `/workspace` и терминал.
Инструмента просмотра экрана/управления Windows и локальных навыков нет.
Установка приложения Codex сама по себе не доказывает, что этот облачный
разговор получил доступ к компьютеру. В локальном сеансе сначала проверить
доступные инструменты. Если управления окнами нет, прямо сообщить об этом.

Пользователь откроет FL Studio и сам укажет папки, в которых разрешает
работать. До этого не изменять его проекты, плагины или другие файлы.
Разрешённые папки ещё не названы. Существующий FLP сохранять отдельной копией.

## Цель и обязательные ограничения

Репозиторий: https://github.com/Ananas2000/divalead, ветка `main`.
Нужен максимально близкий к `Diva_original_lead_reference.wav` лид Diva.
Использовать исключительно три длинные входящие ноты на фразу; подъёмы
высоты создаёт внутренний ARP Diva. Ноты 41 → 37 → 36, фраза повторяется
дважды, 180 BPM. Использовать готовый MIDI из пакета: шесть Note On и шесть
Note Off на две фразы. Вариант с 16 входящими нотами и сэмпл MistaTowa исключены.

Пользователь слышал у наших ранних версий лишний воздух/шипение, зажатость
и смещение влево. Приоритет — тембр. Оригинал сам имеет неравные уровни L/R;
выравнивание RMS каналов не доказывает совпадение стерео.

Старый Finish v83 даёт 12416 сэмплов PDC при 48 kHz; такую задержку
пользователь отверг. Сейчас переносим обработку на настоящие эффекты FL.
Полный перенос звучания v83 и совпадение с оригиналом ЕЩЁ НЕ ДОСТИГНУТЫ.
По используемым метрикам v83 пока ближе к оригиналу, чем нативная цепочка.
Не выдавать технический WIP за готовый пресет.

Пакет содержит настоящий h2p Diva, MIDI, исходный рендер Diva, полный WAV,
монтаж для сравнения, A/B и 16 FST: четыре пресета вставок и 12 пресетов
эффектов. Присланные проприетарные DLL в Git не публикуются.

Маршрутизация: SOURCE → параллельно MID и SIDE → SUM → Master.
Прямые пути SOURCE/MID/SIDE в Master отключены. Точные значения Mix и
маршрутизацию брать из актуальной инструкции, не из старых версий.
Source: WaveShaper → Chorus → два Stereo Shaper с парным поворотом фазы.
Далее четыре EQ2 в ветках Mid/Side, кодирование/декодирование Stereo Shaper
и финальная матрица Stereo Shaper.

В Diva относительно v83 принят только PWModDepth +1.00 с прежним KeyFollow2.
Все 281 параметр и 12 MIDI-событий проверены; исходный рендер этого варианта
подтверждён независимым запуском Diva. Старый frozen-v83 raw не подставлять
вместо этого источника.

## Последнее подтверждённое изменение

Проверены более гибкие кривые реального Fruity WaveShaper. Кривая с
коэффициентами c3=0.75, c5=-0.35 и последующая совместная настройка 76
параметров EQ дали устойчивое небольшое улучшение по исходному референсу.
Сравнение шести новых рендеров каждой цепочки: ошибка 1.70825 → 1.69739,
стандартная ошибка разности 0.000918. Это значения функции ошибки,
НЕ проценты сходства. При независимом экспорте получена новая серия
рендеров; актуальные числа читать в verification, а не принимать эти
исследовательские числа за неизменный результат.

Рабочий Chorus имеет свободную фазу LFO. Его рендеры немного различаются;
в пакет кладётся средний по оценке захват из шести, а не лучший удачный.
Байты всех 12 состояний и аудио при нулевой глубине Chorus прошли повторную
загрузку; это не утверждение о совпадении модулированных WAV по отсчётам.
Измеренные PDC эффектов — 0 сэмплов; задержка всей FL Studio и аудиоинтерфейса
ещё не измерялась. FL Studio GUI в облаке не проверялся.

## Как продолжать

Сначала загрузить цепочку в реальной FL Studio 20, проверить все четыре
маршрута, Mix Chorus, отсутствие двойного выхода в Master и прослушать
трёхнотный MIDI. Сделать свежий WAV и сравнить с оригиналом при сопоставимой
громкости. Затем менять тембр и снова рендерить. Пользователь не хочет
вопросов по каждой пробе; сохранять действительно полезные промежуточные
результаты в GitHub вместе с WAV, пресетами и инструкцией.

Сторонние аудиоплагины разрешены, если пользователь может скачать их для
FL Studio 20. Проверять формат Windows x64 VST2/VST3, версию, фактическую
задержку и сохранение настроек. Пока ни один скачанный сторонний плагин
в опубликованную цепочку не добавлен.

В `scripts` есть подготовленный исследовательский хост для дополнительного
нативного эффекта и калибровка Blood Overdrive/Fast Dist, а также локальный
экран ширины импульса Diva под новую кривую. На момент этой передачи они
ЕЩЁ НЕ ПРОШЛИ аудиопроверку и не включены в готовую цепочку. Не путать
подготовленный код с полученным улучшением.

Все номерные версии и архивы сохранять. Не удалять подряд промежуточные
версии. Если облачный и локальный сеансы одновременно пишут в Git, сначала
согласовать очередность и актуальную ветку; не делать force push.

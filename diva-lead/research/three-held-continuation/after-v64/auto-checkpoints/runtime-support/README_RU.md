# Возобновление подготовленной облачной среды

Это снимок рабочего скрипта запуска и фактических проверок, не инструкция установки с нуля. В сохранённой среде скрипт находится в `/workspace/divalead-work/three-held-continuation/start_three_services.py`; его нужно запускать именно в этом подготовленном расположении, а не прямо из этого архивного каталога. Нужны сохранённые исходные источники, соответствующие NEW-базы, Python/Wine/MinGW и приватные исследовательские данные.

Команда: `OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 /workspace/.venvs/divalead/bin/python -B /workspace/divalead-work/three-held-continuation/start_three_services.py`. Повторный запуск реально проверен: существующие процессы сохранены, дубликаты не создаются. Три числовых направления используют бюджет2+1+1, независимая программа сохраняет только завершённые проверки. Точное совпадение не достигнуто.

Автобэкап запускается `auto_backup_three.py` в том же приватном каталоге, его код сохранён в `automation/` каждого автоматического снимка. Он проверяет источник,281 параметр,12 входящих событий, все12 причинных случаев, неизменные ограничения, независимо повторяет путь собственной NEW-базы и fixture, формирует WAV/AB/инструкцию, отправляет в Git и сверяет HTTP-байты. Уже выполнены две явные проверки реальной публикации и последующая автоматическая публикация без ручного запуска. Включены и новые завершённые более слабые варианты, помеченные отдельно. Большие численные журналы сохраняются как точный gzip с SHA исходного JSON и картой распаковки.

Перед ручной записью в Git создать приватный `auto-backup.pause`, дождаться состояния `paused_for_manual_Git_work` в `auto-backup-state.json` и удерживать `auto-backup-Git.lock`. После завершения удалить только свою паузу и проверить возвращение программы к ожиданию/публикации. Расчёты при такой паузе не останавливаются. Программа не сбрасывает изменения пользователя, не делает force-push, не превращает недопустимую численную точку в доказанный результат и не объявляет совпадение.

Процессы продолжают работать в текущей запущенной среде. Сохранение черновика конфигурации не публикует снимок и не подтверждает восстановление в новой задаче; для будущего старта нужны Save/Publish в настройках облачной среды. GUI FL Studio и прослушивание ассистентом не выполнялись. Для прослушивания использовать готовые WAV и инструкции соответствующего снимка.

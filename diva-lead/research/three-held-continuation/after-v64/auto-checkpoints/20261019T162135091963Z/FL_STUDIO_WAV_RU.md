# Загрузить проверенный исследовательский WAV в FL Studio

Проект 180 BPM, желательно 48kHz. Перетащить `READY_THREE_HELD_RESEARCH_WIP.wav` в Playlist: Normalize выключен, Pitch 0, Time stretching Resample, Time Reset, канальный и микшерный уровни 0dB, панорама по центру, Master без лимитера и дополнительной обработки. WAV уже обработан, Finish повторно не добавлять.

`AB_ORIGINAL_V64_CURRENT_THREE_HELD_WIP.wav` / MP3: оригинал с 0 с → полный v64 с 4,168с → этот исследовательский вариант с 8,336с. Каждый вариант выровнен одним общим RMS-множителем для всего стерео. Входящие ноты — три удержания на фразу, два прохода, внутренний ARP Diva.

Это исследование новее DLL полного v65. Для игры MIDI пользоваться полным комплектом v65 и его собственной инструкцией. Сохранённые здесь пресет/исходники служат воспроизводимым данным исследования; DLL другой версии не воспроизводит автоматически новые коэффициенты. Точное совпадение не достигнуто. GUI FL Studio здесь не проверялся.

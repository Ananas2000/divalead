# Выбор основы среди всех сохранённых версий

Текущий опубликованный проверенный вариант после дальнейшего подбора: [оригинал → уточнённый лид](AB_REFERENCE_AFTER_EXTENDED_CORE_SOURCE_WIP.wav), второй фрагмент с **4.168 с**. Полный снимок — `after-extended-core-source`, указатель — `CURRENT_RESEARCH_MODEL.json`. Это продолжение выбранной v53; точное совпадение не достигнуто. Работающий частный цикл может уже иметь более новый результат; он требует отдельного сохранения и проверки перед публикацией. Ниже сохранены исходное сравнение и предыдущие этапы.

Для продолжения выбрана **v53 WIP**, пресет и эффект вместе. Это первое место по заранее заданному набору измерений, с небольшим преимуществом над исследовательским вариантом `after-v56`. Точное совпадение и субъективное превосходство не установлены. Номер последней версии не определяет выбор.

Проверено состояние репозитория `05b5b5e99b59a8f08c2c8307d9dbeda9322c7d27`: 565 WAV, 57 ZIP. Все 557 WAV внутри архивов побайтно совпали с файлами в папках; дополнительных аудиовариантов там нет. Из 565 путей 173 содержат оригинал или A/B с оригиналом и исключены из кандидатов. Остальные 392 пути после удаления точных дублей дают 174 отдельных сигнала. Для v1, у которой нет сохранённого рендера, дополнительно запущена предоставленная Diva с пресетом из её архива и современным общим исполнением. Всего **175 сравниваемых сигналов**, покрывающих v1–v56, сухие и обработанные альтернативы, chorus-test и сохранённые исследовательские WAV.

Исходный загруженный WAV и сохранённый `Diva_original_lead_reference.wav` совпадают по декодированным сэмплам. MistaTowa не используется.

## Решение и ограничения

| Вариант | Составная ошибка, меньше лучше | 24 гармоники, dB | Верхние гармоники M/S, dB | Нижние гармоники M/S, dB | ERB-полосы, dB |
|---|---:|---:|---:|---:|---:|
| **v53** | **0.995133** | 1.057498 | 1.535715 | 0.860718 | 1.179777 |
| after-v56 guarded gain | 0.996689 | 1.053427 | 1.558586 | 0.898716 | 1.137570 |
| v51 | 0.998316 | 1.073640 | 1.511852 | 0.853835 | 1.193022 |
| v55 | 1.000000 | 1.053942 | 1.549012 | 0.891547 | 1.179350 |
| v56 | 1.034523 | 1.054996 | 1.976126 | 0.894262 | 1.016856 |

Составная ошибка — взвешенная сумма отношений физических ошибок к v55, **не процент сходства**. Веса: 24 гармоники 25%, верхние гармоники 20%, ERB 15%, нижние гармоники 10%, относительные фазы Mid 7%, верхняя междугармоническая энергия 5%, спектр всего фрагмента 5%, огибающая 5%, уровни нот 3%, фазы L/R 2.5%, баланс L/R 2.5%. Результат зависит от этих предпочтений; v53 не лучшая по каждому критерию. В 10000 детерминированных вариациях весов Dirichlet(weight×100) v53 выбрана 7235 раз, after-v56 — 2688, v51 — 76, v56 — 1. Это проверка устойчивости решения к весам, не вероятность субъективного совпадения.

Гармоники и M/S-энергии измеряются отдельно в 16 окнах нот; общий спектр не заменяет эту проверку. Маски между гармониками включают модуляцию, оконные утечки и кодек, отдельно шипение они не измеряют. Это те же фрагменты, на которых ведётся подбор, без отложенной проверки. Прослушивание моделью не заявляется.

Все версии приводятся к одному временному фрагменту с учётом сохранённого выравнивания, PDC и общего внешнего монтажа. Индивидуального выравнивания, изменения громкости или высоты отдельных нот нет. Сохранённые `ALIGNED`/`REFERENCE_EDIT` проверены также в исходном виде. У старых v2/v3 нет метаданных сдвига: для сырых файлов использовано 992 сэмпла, как у v4/v5; этот сдвиг не оптимизировался. У v1 и некоторых v3 подгонка несущей достигает границ: это отмечено в `ranking.json`, а их оценки не следует интерпретировать как достоверную оценку только тембра. Для выбранной v53 ограничение не срабатывает. Результаты старых неверно настроенных исполнений не доказывают, что их пресеты нельзя улучшить новым MIDI.

## Свежая проверка выбранной v53

Два новых запуска предоставленной Diva воспроизвели исходный WAV и все 281 параметр побайтно. Windows-эффект v53 воспроизвёл сохранённый обработанный WAV побитно. Windows/native: максимальная ошибка `7.4505805969e-9`; полная независимая цепочка с подходящей базой NEW247: `2.1596022104e-7`, прежний допуск `3e-7`. Монтаж свежего результата совпал с сохранённым монтажом v53. Подробности — `fresh_selected53_validation.json`.

Для v53 подходят её источник и база 247. База 268 относится к другому источнику v54–v56 и здесь не используется. Совместное дальнейшее уточнение меняет только существующие 93 усиления и 18 фазовых коэффициентов, сохраняя источник v53, MIDI и обработку перед STFT. Новые результаты требуют реального рендера и свежей подгонки несущих перед принятием.

Из корня репозитория, с установленными NumPy/SciPy/SoundFile:

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -B diva-lead/research/repository-selection/compare_all.py
```

Выход — `~/.cache/divalead-repository-selection` или `DIVALEAD_SELECTION_WORK`. Нужны только сохранённые аудио, без Diva и приватных историй. Список входов зафиксирован в `all_audio_inventory.json`, поэтому новые файлы исследования не меняют историческое сравнение. Запуск считает все варианты заново; результаты с другим хешем сигнала не переиспользуются. Проверка переносимой копии действительно выполнила инвентаризацию всех входов и пересчитала v53 с совпадением всех критериев до `1e-12`; полного повторного прогона переносимой копии не заявляется.

`ranking.tsv` — компактная таблица всех кандидатов; `ranking.json` — критерии, диагностика и алиасы; `candidate_inventory.json` — преобразования и исключения; `archive_audio_dedup.json` — связь архивов с одинаковыми файлами. `V1_FRESH_CONTROLLED_REFERENCE_EDIT.wav` и дамп параметров сохраняют добавленный контроль v1.

WAV для прослушивания выбранной основы: [оригинал → v53](../../v53-wip/AB_REFERENCE_V53_WIP_HARMONIC_RESPONSE_AND_UPPER.wav), v53 начинается с **4.168 с**. Рабочая основа остаётся WIP.

## Проверенный результат дальнейшего подбора от v53

[Оригинал → продолжение v53](AB_REFERENCE_CONTINUED53_WIP.wav), начало второго фрагмента **4.168 с**. [Оригинал → исходная v53 → продолжение](AB_REFERENCE_V53_CONTINUED53_WIP.wav), начала 0 / 4.168 / 8.336 с. В каждом фрагменте один общий RMS-множитель, без поканальной или понoтной коррекции сравнения.

Это **исследовательский WAV и 111 существующих коэффициентов**, не новая готовая версия пресета/эффекта. Исходник Diva, MIDI и обработка перед STFT взяты именно из выбранной v53. Общая оценка после свежей подгонки несущих уменьшилась с `0.995132955` до `0.977415418`; ошибки 24 гармоник, нижних и верхних гармоник, ERB-полос, огибающей и уровней нот уменьшились. Полный набор изменений, включая регрессии, сохранён в `continued53_actual_validation.json`: относительные фазы Mid, фазы L/R и суммарная ошибка верхней междугармонической энергии немного хуже; верхние гармоники Mid 3.5–4.5 и 4.5–6.5 кГц и Side 3.5–4.5 и 6.5–10 кГц имеют отдельные ухудшения. Суммарный выигрыш не отменяет их и не означает точное совпадение.

Выполнены свежий запуск настоящей Diva, сверка всех 281 параметра и исходных сэмплов, Windows/native, независимая спектральная стадия и полная независимая цепочка NEW247. Максимальные ошибки: `4.6566128731e-10`, `1.0758044433e-7`, `2.0780042109e-7` соответственно; допуски прежние. Отдельный запуск переносимого кода восстановил этот реальный WAV с ошибкой `1.0758044433e-7` при допуске `2e-7`. Это проверки реализации, не измерение слышимого сходства.

Для продолжения без приватных историй:

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -B diva-lead/research/repository-selection/refine_selected53.py --check-only
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -B diva-lead/research/repository-selection/refine_selected53.py --render-seed
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -B diva-lead/research/repository-selection/refine_selected53.py --slsqp
```

Первые две команды действительно проверены. Последняя продолжает подбор от проверенного seed/saved best с четырьмя численными процессами, сохраняя лучшую допустимую точку. Их число и набор CPU можно задать через `DIVALEAD_NUMERIC_WORKERS` и `DIVALEAD_CPU_SET` (например, `2` и `0,1` для двух одновременных численных направлений). Она накладывает 31 явное ограничение положительности усилений на всём непрерывном интервале несущих 45–220 Гц; аналитический якобиан проверен конечными разностями. Фиксированные несущие используются только для гладкости поиска; кандидат после него требует свежей подгонки несущих и реального рендера. Прогон L-BFGS-B завершился лимитом 45 итераций/127 оценок центра; затем SLSQP завершился лимитом 45 итераций/66 оценок центра за 582 с. Лучший допустимый SLSQP-кандидат прошёл описанные реальные проверки и сохранён здесь. Завершение бюджета не означает достижения совпадения; новой полной проверки плагина в FL Studio не заявляется. Следующие расчёты идут отдельно от сохранённого проверенного бэкапа.

## Продолжение: реакция гармоник, основной тембр и реальный источник

Сохранены полные проверенные модели `after-hf-power`, `after-core` и `after-core-source`. Первая добавляет 69 уточнений уже существующих целей мощности к завершённому HF-подбору. Вторая уточняет 147 существующих значений основной матрицы. Третья использует ту же матрицу и меняет в настоящей Diva только **Tune2: 24.03 → 24.02**, то есть на один цент. Все ноты, MIDI, остальная обработка и количество коэффициентов/состояний прежние. Это параметры исследования и контрольные WAV; готового нового эффекта для FL Studio здесь не заявляется.

| Ошибка | Исходная v53 | После HF и реакции гармоник | После основной матрицы | Матрица + новый источник |
|---|---:|---:|---:|---:|
| Составная ошибка | 0.995133 | 0.968078 | 0.954415 | **0.954167** |
| 24 гармоники, dB | 1.057498 | **1.055264** | 1.057102 | 1.057397 |
| Нижние гармоники M/S, dB | 0.860718 | 0.826232 | 0.740639 | **0.739739** |
| Верхние гармоники M/S, dB | 1.535715 | 1.472187 | **1.469617** | 1.473277 |
| ERB-полосы, dB | 1.179777 | 1.077353 | 1.061801 | **1.055332** |
| Уровни нот, dB | 0.059138 | 0.056290 | 0.055566 | **0.055565** |

Веса общего сравнения прежние. При выборе основной матрицы верхняя граница ошибки H24 привязана к **исходной выбранной v53**: не хуже неё, с сохранением остальных ограничений этапа. Это позволяет принять совместный выигрыш нижнего диапазона и уровней при небольшом ухудшении H24 относительно промежуточного `after-hf-power`. Первоначальный локальный предел H24 ×1.001 оказался строже этого решения; его отказ и отдельный пересмотр сохранены в `after-core/choice.json`. **Допуски проверки реализации не менялись.**

Для нового источника реально проверен 21 пресет Diva: ширина импульса, смешение осцилляторов, Tune2, частота и резонанс фильтра. Все 281 параметр и все поля H2P сверены: изменялись только заявленные значения. Таблица — `actual_Diva_source_grid.json`. Победившая правка источника даёт небольшой смешанный выигрыш; без новой основной матрицы она не заменяет её. Фазовый подбор также прошёл реальную проверку, но его отдельный результат уступил текущему по общему набору ошибок и не выбран основой. Все последующие сравниваемые реальные модели — `later_actual_model_comparison.json`.

Для `after-core-source` выполнены свежий рендер предоставленной Diva, точное повторение исходных сэмплов и дампа нового источника, Windows/native, независимая спектральная стадия и **новая независимо построенная база обработки до STFT**. Полная ошибка `1.8171884958e-7` при допуске `3e-7`; база нового источника совпала с отдельным C-расчётом до `7.1146530667e-8` при допуске `5e-7`. Старая база 247 применяется к неизменённому источнику v53 и **не использовалась для изменённого источника**. Точная база и результат проверки записаны в `after-core-source/validation.json`.

Исправлен тип аргумента частоты дискретизации в приватной проверочной обёртке native: он соответствует C `int`. Все ранее опубликованные снимки этой серии повторно сверены с Windows с правильным типом; результаты прошли прежний допуск. Они перечислены в `native_signature_recheck.json`. Новые реальные проверки выполнены с правильным интерфейсом.

Полные модели и их исходные аудиофикстуры можно воспроизвести без приватных историй и без Diva:

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -B diva-lead/research/repository-selection/replay_spectral_model.py
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -B diva-lead/research/repository-selection/refine_complete_core.py --check-only
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -B diva-lead/research/repository-selection/refine_complete_core.py
```

Первые две команды действительно проверены на полном снимке нового источника. Воспроизведение использует ровно указанные в `source_manifest.json` исходники и проверяет SHA-256. Максимальная ошибка спектрального воспроизведения `after-core-source` — `1.0509250742e-7` при допуске `2e-7`. Это повтор спектральной стадии на сохранённом входе; независимую обработку до STFT он заново не строит. Полная проверка новой базы выполнена отдельно и сохранена в отчёте. Пресет в этом снимке сам по себе не воспроизводит новую цепочку обработки.

Общий численный подбор по умолчанию начинает с текущей проверенной модели из `CURRENT_RESEARCH_MODEL.json`, поддерживает оба источника и сохраняет 147-мерные координаты только для соответствующей базы. В этом скрипте изменяются **147 существующих коэффициентов основной матрицы**, ограничиваются общие ошибки, а H24 остаётся не хуже исходной v53. Предыдущий результат с совпадающим хешем базы читается до записи начальной точки; чужой результат не переиспользуется. Новые точки требуют настоящего Diva/Windows-рендера и подходящей новой независимой базы до публикации. Сходимость или точное совпадение не объявляются по одному завершению бюджета.

## Предыдущий проверенный снимок полного подбора

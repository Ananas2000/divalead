# Продолжение после v56 WIP

Совпадение с оригиналом не достигнуто. В v56 общая ошибка энергии 40 ERB-полос снизилась, но раздельная проверка верхних гармоник по нотам выявила ухудшение. Поэтому снижение одной средней ошибки не считается достаточным результатом. v55 и v56 сохранены для сравнения.

Здесь сохранён самостоятельный способ продолжить подбор из проверенной v55 без приватных историй, путей старых поисков или бинарника Diva. Скрипт использует только включённые в репозиторий WAV, настройки и независимую спектральную реализацию v55. Сэмпл MistaTowa не используется.

```sh
python -B diva-lead/research/after-v56/fit_constrained_gains.py --check-only
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -B diva-lead/research/after-v56/fit_constrained_gains.py
```

Нужны Python, NumPy, SciPy и soundfile. Вывод сохраняется за пределами репозитория в `~/.cache/divalead-after-v56/constrained-fit`; другой рабочий каталог задаётся переменной `DIVALEAD_RESEARCH_WORK`. Для старта с прежнего сохранённого набора смещений положите JSON с полем `offsets` из 93 чисел в `<рабочий каталог>/resume_offsets.json`. Численные процессы используют до двух доступных CPU.

`--check-only` проверяет нейтральный результат по настоящему Windows-WAV v55, два ненулевых набора относительно полного независимого расчёта, воспроизведение верхнего диагностического спектра и допустимость начальных ограничений. Для этих двух ненулевых наборов допуск прежний 2e-10; для нейтрального WAV — 2e-7.

Подбор меняет только существующие 93 коэффициента усилений гармоник. В эффект не добавлены коэффициенты, состояния или обработка. SLSQP использует явные ограничения на первые 24 гармоники, спектр, огибающие, уровни нот, баланс каналов, пики и положительность усиления. Отдельно контролируется ошибка верхних гармоник Mid/Side в четырёх полосах по 16 нотным окнам: в поиске допускается отношение не выше 1,009 от ошибки v55. Для остальных двух компонентов используется предел 1,02. Частотная энергия ERB и ошибки раздельных компонентов входят в целевую функцию вместе.

Для гладкости поиска используются фиксированные несущие из настоящего WAV v55 и FFT 65536. После получения кандидата обязательно заново подобрать несущие на его настоящем Windows-рендере и проверить верхние гармоники; предел свежей проверки — 1,01 от v55. Эти маски включают модуляцию, утечки окон и кодек. Они не измеряют отдельно слышимое шипение. Сравнения выполняются на окнах подбора, не на отложенной выборке.

`best-edit.wav`, `best-basepdc.wav`, `best.json`, `history.json`, `optimizer.json` — исследовательские файлы. Это не новый готовый пресет, не результат прослушивания и не подтверждение совпадения. Перед переносом результата в эффект нужны пересборка C/Windows, свежий рендер Diva, проверка всех 281 параметра и исходных аудиосэмплов, Windows/native/независимая цепочка, переносимые проверки и новый A/B WAV. При неизменных источнике 267 и обработке до STFT применима независимая база 268. При изменении источника или этой части обработки база должна быть пересчитана.

Сводка завершённых опытов — `rejected_experiments.json`. Не повторять их автоматически как незавершённые. Отдельный приватный прототип кубической зависимости усилений от частоты в опубликованный эффект не включён.

## Проверенный исследовательский WAV

`AB_REFERENCE_GUARDED_GAIN_RESEARCH_WIP.wav`: оригинал → вариант с ограничениями на верхние гармоники; второй фрагмент начинается с **4,168 с**. Это PCM24 WAV с одним RMS-множителем на весь второй фрагмент. В `GUARDED_GAIN_RESEARCH_EDIT.wav` сохранён исходный монтаж настоящего Windows-рендера. Это исследовательское сравнение, отдельная новая версия пресета или эффекта не выпущена.

Этот вариант отдельно прошёл две свежие загрузки предоставленной Diva, проверку всех 281 параметра и исходных аудиосэмплов, Windows/native/независимую цепочку и свежий подбор несущих для верхнего диагностического спектра. Полный комплект проверок нового публичного плагина для него не заявляется. Все параметры усилений и доказательства — `feasible_gain_seed.json`.

| Ошибка относительно оригинала | v55 | v56 | Исследовательский вариант |
|---|---:|---:|---:|
| Энергия ERB-полос, dB | 1.179349826 | 1.016855948 | 1.137569547 |
| Первые 24 гармоники, dB | 1.053942271 | 1.054995763 | 1.053426697 |
| Гармонические маски 6,5–10 кГц, Mid, dB RMS | 2.472109849 | 3.351195648 | 2.493427141 |
| Гармонические маски 10–14 кГц, Mid, dB RMS | 1.968798842 | 2.236579470 | 1.987510424 |

Компромисс виден в таблице: ERB-ошибка хуже v56, а верхние гармоники заметно ближе к уровню v55. Относительно v55 ошибки верхних гармоник могут вырасти до 1,01 раза; это предел отношения диагностических ошибок, не процент сходства звука. Полного совпадения и субъективного улучшения эти измерения не подтверждают.

Для независимого восстановления проверенного монтажа:

```sh
python -B diva-lead/research/after-v56/fit_constrained_gains.py --render-seed
```

Команда сверяет расчёт с включённым настоящим Windows-WAV при прежнем допуске 2e-7. Обычный запуск подбора выбирает лучший допустимый старт из `resume_offsets.json`, прежнего `best.json` и включённого проверенного набора. Сохраняются `best.json` и атомарный `latest_center.json`; для восстановления используется допустимый лучший набор, состояние матрицы SLSQP не восстанавливается. При длительном запуске нужен отдельный процесс с журналом; наличие `/proc/<pid>` само по себе не подтверждает работу процесса, состояние Z означает завершение.

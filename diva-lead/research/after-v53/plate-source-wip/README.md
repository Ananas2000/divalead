# Источник Diva после v53 — WIP

Промежуточная проба, совпадение с оригиналом ещё не достигнуто. Изменён только пресет Diva; используется **неизменённый эффект v53**.

Загрузить `Diva_Lead_Plate_Source_after_v53_WIP.h2p`, следом `Diva_Lead_Finish_v53_WIP_x64.dll` из [v53](../../../v53-wip/README.md). Amount = 1, Output = +1,852506397 dB, PDC включена. MIDI v53, 180 BPM. Бинарник Diva не включён. GUI FL Studio не проверялся.

После 13 контрольных и 62 уточняющих рендеров настоящей Diva выбраны четыре изменения встроенной реверберации: Wet 1,12 → 1,88; Decay 35,25 → 33,25; Damp 72 → 54,28; Diff 92 → 84. Остальные 277 параметров и MIDI прежние. H2P-имя `Diff` соответствует отображаемому `Diffusion`.

`AB_REFERENCE_PLATE_SOURCE_AFTER_V53_WIP.wav`: оригинал → эта проба, начало пробы **4,168 с**.

# Diva lead v14 — промежуточный бэкап

**Совпадение ещё не достигнуто.** V14 уменьшает расстояние спектров всего фрагмента и уточняет стереофазу. Взвешенная ошибка стационарного спектра, огибающая12мс и баланс L/R немного хуже v13. MistaTowa не использовался. Прослушивание и проверка в FL Studio здесь не выполнялись.

1. Загрузить Diva_Lead_v14_WIP.h2p в свою Diva.
2. После Diva поставить Diva_Lead_Finish_v14_WIP_x64.dll как Windows VST2 x64: Amount =100%, Output =+1,85251dB.
3. Импортировать Diva_PERFORMANCE_VIDEO_180BPM.mid, темп180BPM, сохранить velocity. Короткий REFERENCE MIDI оставлен отдельно.
4. Включить компенсацию задержки DAW:8320сэмплов/173,33мс при48кГц. Выравнивание WAV на819сэмплов относится только к сравнению с референсом.

Источник Diva и MIDI совпадают с v13. Изменены общие фильтры после Diva: коррекция учитывает весь фрагмент, включая переходы между нотами. Дополнительные фильтры отслеживают энергию того же входящего сигнала и сохраняют уровни после EQ. Записанного лида и нотного расписания внутри DLL нет.

A/B: **оригинал → v13 → v14**, RMS уравнена по целым фрагментам. VIDEO_REFERENCE_EDIT сравнивает вырезки непрерывного исполнения; REFERENCE_PATTERN — отдельное короткое исполнение. WAV — PCM24, MP3 — копия для прослушивания. DIVA_DRY — Diva без встроенных FX; DIVA_ONLY — пресет до Finish. VIDEO_DIVA_ONLY — полный шестисекундный вход, VIDEO — обработка без задержки. FINAL в именах короткого исполнения продолжает соглашение прошлых версий и не означает готовое совпадение.

Непрерывное исполнение с одинаковыми вырезками, меньшая ошибка лучше:

Все ухудшения и отдельное короткое исполнение сохранены в validation.json. Числа не являются процентом сходства на слух. Нулевой хвост — следствие монтажа. Начало второй вырезки захватывает уже звучащий предыдущий фрагмент исходного видео; сравнение всего оригинала сохраняет этот участок. Его источник не подменён дополнительным сэмплом.

Проверены два свежих запуска Diva, реальные Windows-рендеры, совпадение с расчётом, размеры блоков, остановленный преролл, 44,1/48/96/192 кГц, тишина, Amount 0, VST chunk и прохождение между каналами. Все 131072 коэффициента воспроизводятся побитно из JSON без аудио. Вырезки сравнения имеют 176064 сэмпла; экспорт сохраняет начало FIR, как исправленный v13. Исходники и независимые измерения находятся в analysis/.

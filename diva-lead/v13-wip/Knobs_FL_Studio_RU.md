# Diva lead v13 — промежуточный бэкап

**Совпадение ещё не достигнуто.** V13 уменьшает измеренную спектральную ошибку и уточняет уровни нот. Спектр всего фрагмента и фаза L/R немного хуже v12; переходы между нотами ещё различаются. MistaTowa не использовался. Прослушивание и проверка в FL Studio здесь не выполнялись.

1. Загрузить Diva_Lead_v13_WIP.h2p в свою Diva.
2. После Diva поставить Diva_Lead_Finish_v13_WIP_x64.dll как Windows VST2 x64: Amount = 100%, Output = +1,85251 dB.
3. Импортировать Diva_PERFORMANCE_VIDEO_180BPM.mid, темп 180 BPM, сохранить velocity. Diva_PERFORMANCE_REFERENCE_180BPM.mid оставлен для короткого монтажа прежних версий.
4. Включить компенсацию задержки DAW:8320 сэмплов / 173,33 мс при 48 кГц. Выравнивание WAV на 819 сэмплов относится только к сравнению с референсом.

Сохранённый H2P уже содержит изменения Diva: OSC Drift 24,8, TuneSlop 3,86, FineTune −0,18 цента, ENV1 Attack 3,02 / Sustain 93,85, Plate2 Wet 1,12% / Decay 35,25 / Damp 72. DLL обрабатывает входящий сигнал общими фильтрами и динамикой. Дополнительные фильтры отслеживают энергию того же сигнала и выравнивают её после коррекции EQ. Записанного лида и нотной последовательности внутри DLL нет.

DIVA_DRY — Diva без встроенных FX; DIVA_ONLY — сохранённый пресет до Finish. FINAL_WITH_PDC, FINAL и FINAL_ALIGNED — короткое исполнение; слово FINAL в имени продолжает прежнее соглашение и не означает готовое совпадение. VIDEO_DIVA_ONLY — полный шестисекундный вход; VIDEO — обработанный рендер с удалённой задержкой, около 5,83 секунды. VIDEO_REFERENCE_EDIT — две вырезки непрерывного рендера по монтажу оригинала. Нулевой хвост возникает от вырезки.

A/B: **оригинал → v12 → v13**, нормализация RMS по каждому целому фрагменту. VIDEO_REFERENCE_EDIT сравнивает непрерывное исполнение с вырезками; REFERENCE_PATTERN — отдельный короткий MIDI. WAV — PCM24, MP3 — копия для прослушивания.

Измерения непрерывного исполнения с одинаковыми вырезками, меньшая ошибка лучше:

Эти числа не являются процентом звукового совпадения. Стереофаза и спектр всего фрагмента немного ухудшились; все регрессии сохранены в validation.json. Короткое исполнение измерено отдельно.

Исправлен также экспорт сравнения: теперь выравнивается исходный WAV с задержкой DLL, сохраняя начало FIR. Раньше задержка обрезалась до выравнивания, и в начале вставлялись нули. Это отдельное исправление сравнения. Предыдущие WAV v12 в этом комплекте заново экспортированы из неизменённых v12 WITH_PDC; опубликованные файлы v12 сохранены. Все отрезки сравнения имеют 176064 сэмпла.

Проверены два свежих запуска H2P, реальный Windows-рендер, совпадение с расчётом, размеры блоков, остановленный преролл, 44,1/48/96/192 кГц, тишина, Amount 0, VST chunk и прохождение между каналами. Все 131072 коэффициента воспроизводятся побитно из JSON без аудио; измерения независимо пересчитаны из WAV. Задержка прежняя, но вычислительная работа FIR примерно удвоилась относительно v12. Исходники и проверки находятся в analysis/.

# Diva Lead v29 WIP — верхний спектр и стерео

Промежуточный бекап продолжающегося подбора. Совпадение с оригиналом ещё не достигнуто. MistaTowa не используется.

Загрузите `Diva_Lead_v29_WIP.h2p` в Diva и поставьте после неё `Diva_Lead_Finish_v29_WIP_x64.dll` как VST2 эффект Windows x64. Amount — 100%, Output — +1,8525064 dB. Темп — 180 BPM, MIDI — `Diva_PERFORMANCE_VIDEO_180BPM.mid`. Источник Diva и MIDI идентичны v28; остальные ручки источника описаны в [v25](../v25-wip/Knobs_FL_Studio_RU.md). Для нового обработанного варианта нужен эффект v29.

[A/B оригинал → v29](AB_REFERENCE_V29_WIP_UPPER_STEREO.mp3): v29 начинается с **4,168 с**, весь файл — 7,836 с. Есть [WAV](AB_REFERENCE_V29_WIP_UPPER_STEREO.wav) и [оригинал → v28 → v29](AB_REFERENCE_V28_V29_WIP_UPPER_STEREO.mp3). Громкость выровнена по целым фрагментам, без нормализации отдельных нот. Для прямого сравнения — `Diva_v29_VIDEO_REFERENCE_EDIT.wav`; непрерывный звук — `Diva_v29_VIDEO.wav`. Нулевые разрывы EDIT повторяют внешние вырезки референса.

Компенсация задержки DAW: **12416 сэмплов / 258,667 мс при 48 кГц**, как у v26/v27/v28. При 44,1/96/192 кГц проверены 11414/24704/49280 сэмплов.

V29 уточняет баланс гармонической и рассеянной верхней энергии отдельно в Mid и Side. Плавная комплексная матрица действует между 3,5 и 14 кГц и встроена в прежний спектральный этап, без новой задержки. Верхние составляющие перераспределены между центром и боками; общая ширина сохранена. Частота основного тона оценивается из входного звука. Маска включает модуляцию, дрейф, переходы и кодек, поэтому не выделяет слышимое шипение отдельно и не доказывает субъективную чистоту звука. Полные данные всех полос — `analysis/mid_side_measurements.json`.

Две свежие загрузки пользовательской Diva дали одинаковые WAV, идентичные источнику v28. Настоящий Windows DLL совпал с native до 1,86×10⁻⁹ при 48 кГц; отдельный полный расчёт SciPy — до 1,22×10⁻⁷. Проверены шесть размеров блока, preroll3/17, четыре частоты дискретизации, PDC, тишина, Amount0, состояние VST, L/R, 12 произвольных входных сигналов и причинность. Все 94 коэффициента нового спектрального этапа проверяются независимо. Прослушивание и FL Studio здесь не выполнялись.

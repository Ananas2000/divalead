# Diva lead v12 — промежуточный бэкап

**Совпадение ещё не достигнуто.** V12 продолжает v11: уточнены сохранённые настройки Diva, стереофильтр и динамическая обработка. Улучшились измерения фазы и баланса L/R. Спектральная ошибка почти не изменилась; переходы между нотами требуют дальнейшей работы. MistaTowa не использовался. Прослушивание и проверка в FL Studio здесь не выполнялись.

1. Загрузить `Diva_Lead_v12_WIP.h2p` в свою Diva.
2. После Diva поставить `Diva_Lead_Finish_v12_WIP_x64.dll` как Windows VST2 x64. Amount = 100%, Output = +1,85 dB.
3. Использовать `Diva_PERFORMANCE_VIDEO_180BPM.mid`, темп 180 BPM. `Diva_PERFORMANCE_REFERENCE_180BPM.mid` воспроизводит укороченный монтаж из прежних версий; это отдельное исполнение.
4. Включить компенсацию задержки DAW: DLL сообщает **8320 сэмплов / 173,33 мс при 48 кГц**, как v11. Отдельные 843 сэмпла выравнивания WAV относятся к сравнению с вырезкой.

`Diva_v12_DIVA_DRY.wav` содержит Diva без встроенных эффектов; `DIVA_ONLY` — сохранённый пресет со встроенными эффектами, без Finish. `FINAL_WITH_PDC`, `FINAL` и `FINAL_ALIGNED` относятся к короткому MIDI-исполнению. `VIDEO_DIVA_ONLY` — полный шестисекундный вход; у обработанного `VIDEO` удалена задержка DLL, поэтому его длительность около 5,83 секунды. `VIDEO_REFERENCE_EDIT` содержит две вырезки из этого непрерывного рендера, соответствующие монтажу референса. Вырезки и тишина применяются к WAV отдельно; DLL не содержит нотной последовательности или записанного лида.

Два A/B-файла дают порядок **оригинал → v11 → v12**, с общей нормализацией RMS каждого фрагмента. `REFERENCE_PATTERN` сравнивает короткий MIDI; `VIDEO_REFERENCE_EDIT` — одинаковые вырезки непрерывного исполнения. WAV содержит PCM24, MP3 — копию для удобного прослушивания.

Измерения короткого исполнения, меньшая ошибка лучше:

| Измерение | v11 | v12 |
|---|---:|---:|
| Взвешенная спектральная ошибка, dB | 2,9687 | 2,9684 |
| Фаза L/R, градусы | 4,8100 | 4,1237 |
| Баланс L/R, dB | 1,3237 | 1,0726 |
| Ошибка огибающей 12 мс | 0,110205 | 0,109783 |
| Ошибка уровней нот, dB | 0,086571 | 0,081414 |
| Ошибка корреляций пяти полос | 0,000107 | 0,001632 |

Ширина стерео в коротком исполнении стала менее точной. В непрерывном исполнении фаза улучшилась 4,8633 → 4,0131°, баланс — 1,3666 → 1,0989 dB; спектральная ошибка слегка выросла 3,0483 → 3,0490 dB. Ошибка огибающей 12 мс уменьшилась 0,123181 → 0,122757. Эти числа **не являются процентом звукового совпадения**. Нулевой хвост после монтажа — следствие вырезки, а не улучшение синтеза.

Проверены два свежих запуска сохранённого H2P, настоящий Windows-рендер DLL, совпадение с расчётом (максимальное расхождение 5,96×10⁻⁸), размеры блоков 47/127/128/511/512/2048, остановленный преролл, 44,1/48/96/192 кГц, тишина, Amount = 0, сохранение двух ручек через VST chunk и прохождение сигнала между каналами. Коэффициенты воспроизводятся побитно из JSON без чтения аудио. Исходник плагина и независимые измерения находятся в `analysis/`.

Исходное видео использует HE-AACv2, около 32 kbit/s, 44,1 кГц. Повторное кодирование уже подогнанного v11 ухудшило сравнение; кодек в пресет и DLL не добавлен. Его влияние измеримо, но оно не объясняет все оставшиеся расхождения. Неизвестный инструмент в пропущенной части видео к этому лиду не добавлен.

# Diva Lead v52 WIP — уточнение источника Diva и гармоник

Промежуточный бэкап. Совпадение с оригиналом ещё не достигнуто и на слух не подтверждено.

После v51 уточнены существующие усиления гармоник и параметры выравнивания их мощности. Затем выполнены 73 небольшие пробы на настоящей Diva: ширина импульса, смесь осцилляторов, частота и резонанс фильтра, настройка второго осциллятора и разброс строя. Выбраны три изменения:

| Параметр Diva | v51 | v52 |
|---|---:|---:|
| OSC OscMix | 5,55 | 5,72 |
| VCF1 Freq | 145,64 | 144,17 |
| OSC Tune2 | 24,02 | 24,03 |

Остальные 278 параметров и MIDI прежние. Синхронизация осцилляторов сохранена: её отключение заметно ухудшало измерения. Пробы ослабления ранних стадий обработки также отклонены. Подбор ориентирован на сам тембр; смещение влево остаётся отдельной задачей. Явные стереонастройки прежние, но каналы могут немного меняться вместе с исходной волной.

## Использование и сравнение

1. Загрузить `Diva_Lead_v52_WIP.h2p` в предоставленную Diva.
2. Следом поставить `Diva_Lead_Finish_v52_WIP_x64.dll`: Amount = 1, Output = +1,852506397 dB, PDC включена.
3. MIDI — `Diva_PERFORMANCE_VIDEO_180BPM.mid`, 180 BPM.

Нужны пресет и эффект этой версии. Бинарник Diva не включён. GUI FL Studio не проверялся.

`AB_REFERENCE_V52_WIP_FINE_DIVA_SOURCE_AND_HARMONICS.wav`: оригинал → v52, начало v52 **4,168 с**. Трёхчастный WAV: оригинал → v51 → v52, начала 0 / 4,168 / 8,336 с. Громкость уравнена одним RMS-множителем на фрагмент. Для точного сравнения используйте WAV.

## Проверки

Для всех 73 проб запущена настоящая Diva и проверен полный дамп 281 параметра. Запрошенные значения совпали с отображением точно, включая изменение Tune2 на 0,01. Выбранный пресет дважды отрендерен заново: оба WAV и дампы битово совпали с выбранной пробой. Затем проверен настоящий Windows-эффект.

Изменение источника требует нового независимого расчёта всей цепочки. Прежняя база 197 не использовалась для проверки нового источника. База 247 заново рассчитывает отдельное ядро 43 параметров, FIR/согласование энергии/Side/динамику/возбудитель и входной трекер с десятью фильтрами. Далее применяется независимый NumPy/SciPy-расчёт спектральной стадии.

Максимальная ошибка новой базы перед STFT — **7.187976236e-08**, полной независимой цепочки — **1.984688865e-07**. Допуски сохранены: 5e-7 для базы, 3e-7 для полной цепочки и 2e-7 для спектрального WAV-фикстура.

Изменены значения 93 существующих коэффициентов усиления гармоник, 115 целей мощности, 23 индивидуальных сил коррекции и существующие параметры реакции/ограничения. Алгоритм прежний: 638 спектральных значений, 47 состояний усиления, прежние FFT/окна/банки фильтров/PDC. Фазы и явные стереонастройки v51 сохранены. Настройки обработки перед STFT прежние; аудиосигнал изменился вместе с Diva.

Проверены свежая Diva, Windows/native/SciPy, блоки 47/127/128/511/512/2048, preroll 3/17, 44,1/48/96/192 кГц, состояние, PDC, тишина, Amount = 0 и каналы. Независимые проверки: 638 значений, 12 произвольных входов без MIDI, четыре переходных сигнала, две отдельно включённые поздние группы, масштаб входа и причинность. ZIP проверяется по CRC, всем SHA256 и извлечённому независимому WAV-расчёту.

# Diva Lead v7 — фаза каналов и уровни нот

V7 уточняет оставшееся отличие: общая корреляция L/R у v6 была близкой к референсу, но фаза и баланс каналов на отдельных обертонах не совпадали. Низкочастотная фазовая модуляция заменена постоянной коррекцией каналов. Заново подобраны тембр, ADS-огибающая и velocity нот на настоящем Diva rev16519. Это реконструкция; исходный пресет и исходные эффекты из видео неизвестны.

## Загрузка в FL Studio

1. Открой **`Diva_Lead_v7.h2p`** в браузере PRESETS самой Diva.
2. Назначь Diva отдельный **Mixer Insert**: фейдер **0 dB**, Pan **по центру**, Channel Volume **100%** для сравнения общей громкости.
3. Положи **`Diva_Lead_Finish_v7_x64.dll`** в папку VST2; добавь её в **Options → Manage plugins → Plugin search paths** и запусти **Find installed plugins**.
4. Добавь **Diva Lead Finish v7** на Insert с Diva: **Amount 100%, Output +2.10 dB**. Это значения по умолчанию. В FL Studio доступны два обычных параметра; своего графического окна у эффекта нет.
5. Установи **180 BPM** и импортируй **`Diva_PERFORMANCE_VIDEO_180BPM.mid`**. Для сравнения с короткой аудиовырезкой используй **`Diva_PERFORMANCE_REFERENCE_180BPM.mid`**.
6. Сохрани velocity из MIDI: **96 / 96 / 110 / 98 / 98 / 113 / 101 / 101**. В v7 **ENV1 Velocity 100**, поэтому эти значения влияют на результат. При переходе с v6 замени пресет и эффект обоими файлами v7; одна замена эффекта не воспроизведёт итоговый WAV.

FX1 и FX2 самой Diva **Off**, ARP **Off**. В отдельном Lead Finish уже сохранены коррекция каналов, мягкая сатурация, общий EQ и стереодобавка верхних частот. Для сухого звука отключи этот FX-слот; соответствующий WAV — **`Diva_v7_DIVA_DRY.wav`**.

## MIDI и видео

Восемь атак исполнения: **F3 F3 F4 C#3 C#3 C#4 C3 C3** в обозначениях FL Studio, MIDI **41 41 53 37 37 49 36 36**. В каждом повторе velocity **96 / 96 / 110 / 98 / 98 / 113 / 101 / 101**. Ноты стоят через половину доли; `gate` **0.949404**, последняя нота **0.787832** от половины доли. Небольшое смещение нечётных шагов уже записано в MIDI; дополнительный swing не нужен.

На видео видны **три удерживаемые ноты** длиной **1½ → 1½ → 1 доля**. Они сохранены отдельно в `Diva_PATTERN_3notes_VIDEO_180BPM.mid`, иллюстрация — `Video_pattern_3_notes.png`. Восемь атак `PERFORMANCE` — реконструкция слышимого исполнения; исходные настройки арпеджиатора/эффекта повторов из видео не установлены. Повтор VIDEO через **8 долей**; REFERENCE через **6.991366 доли**, чтобы учесть монтаж вырезки. Эти два MIDI служат разным вариантам размещения фразы.

`Diva_v7_FINAL.wav` — результат цепочки с первого MIDI события. `Diva_v7_FINAL_ALIGNED.wav` сдвинут на **935 сэмплов / 19.479 мс** исключительно для сравнения с началом аудиовырезки; добавлять такую задержку в FL Studio не требуется. Собственный эффект не добавляет буферной задержки.

## A/B и измерения

`AB_reference_v6_v7.wav` / `.mp3`: **оригинал → v6 → v7**. Начала **0:00.000 / 0:04.168 / 0:08.336**; между фрагментами 0,5 с тишины. Общая RMS-громкость фрагментов уравнена целиком, без выравнивания отдельных нот. Для фазовых измерений использован WAV, MP3 предназначен для удобного прослушивания.

| Ошибка баланса L/R на обертонах, dB | 4.16 | 2.25 |
| Ошибка уровней 16 нот, dB | 0.2461 | 0.1999 |

Ошибка фазы уменьшилась на **64%**, уровней нот — на **19%**. Это снижение отдельных измеренных ошибок, а не проценты сходства на слух. Остаток заметен на части обертонов; первая атака также ещё отличается. **V6 лучше по общей ширине стерео и спектральному расстоянию устойчивых участков.** Активная корреляция L/R: **референс 0,9223 / v6 0.9216 / v7 0.9397**. V7 немного уже референса. Обе версии включены в A/B, чтобы можно было оценить этот компромисс.

Итоговый пресет воспроизведён в двух свежих экземплярах Diva с одинаковым WAV. Обработка готовой Windows DLL реально исполнена под Wine и совпадает с расчётным DSP с максимальной погрешностью **6e-08**. Проверены сохранение состояния, блоки 512/93, запуск после фоновой работы, Amount 0, тишина, 44,1/96 кГц. Перегруза нет. Исходники, параметры, MIDI и измерения включены.

Сравнение численное; запуск FL Studio и субъективное прослушивание здесь не выполнялись. **Точное совпадение и 99% на слух не подтверждены.** Оригинал короткий, вырезан из сжатой записи; его резкий конец не доказывает точный Release исходного пресета. MistaTowa Vol.3 к лиду не относится и не добавлен. Проверка HE-AAC и встроенного chorus Diva не установила исходную цепочку, поэтому выводов о её конкретных эффектах нет.
